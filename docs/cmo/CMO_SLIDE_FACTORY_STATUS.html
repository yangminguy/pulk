구버전 구현과 신규 PRD v3가 병존(중복)하는데, ACR가 신규를 phase 단위로 일부만 만들고 기존 자산·오케스트레이터와 배선을 안 한 채 멈췄습니다.

· 기존 video-room/ = 25단계 상태머신 기반 Script Room v3.1 (509 테스트, 방대하게 완성).

· 신규 cmo-orchestrator/ = PRD v3의 "Orchestrator + Agent + Skill" 재설계. Phase 1 인프라 + Phase 2 Key Content 만 부분 완성.

· 핵심 미스: ① 신규 타입 정의가 5/10에서 중단(커밋 메시지에 "진전 보존"으로 그대로 박제) ② Phase 2 Key Content Agent가 orchestrator에 스킬로 등록 안 됨(고립) ③ Phase 3~10은 기존 자산이 있는데도 v3 아키텍처로 정렬·재활용 안 됨.

· 빌드는 멀쩡합니다 — l5-core typecheck 0, slide-deck 4/4, key-content-planning 59/59 GREEN. 즉 "깨진 것"이 아니라 "절반에서 멈추고 연결이 안 된" 상태.
