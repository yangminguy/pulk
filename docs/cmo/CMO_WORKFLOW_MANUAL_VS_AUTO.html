CMO 콘텐츠 워크플로우 — 수동 입력 vs 자동 초안 점검

기준: PRD v3 (docs/prd/cmo-content-strategy-v3.md) · 기획 재점검용 · 2026-06-09
👤 수동 사장님이 직접 타이핑 🤖 자동초안 CMO(Claude)가 생성 → 사장님은 수정만 🔍 Viewtrap 유튜브 데이터 검증(현재 수동→자동 예정) ✅ 승인 사장님 승인 게이트(승인=다음 단계)
핵심 원칙: 사장님은 "최소 2가지"만 입력 → 나머지는 전부 CMO 자동 초안 → 보고 수정/승인
사장님이 실제로 타이핑하는 곳은 딱 3곳뿐입니다: ① 상품 정보(처음 1회) ② 단계별 "고객이 겪는 핵심 문제" ③ (Phase 1 동안) Viewtrap 검색 결과. 그 외 모든 기획 스텝은 CMO가 이전 스텝 결과를 이어받아 자동 초안하고, 사장님은 카드에서 수정/승인만 합니다.

👤 사장님이 직접 입력하는 것 (이게 전부)

  • 상품 정보 (프로젝트 생성 1회): 상품명 · 카테고리 · 타깃 고객 · 핵심 제안 · 비즈니스 목표 → 이후 모든 단계가 이걸 재사용
  • 고객이 겪는 핵심 문제 (키콘텐츠 단계, 1줄): 예 "콘텐츠를 어떻게 기획하고 만드는지 모름" → 11스텝 자동초안의 출발점
  • Viewtrap 검색 결과 (현재 Phase 1: 수동): CMO가 만든 검색축으로 사장님이 app.viewtrap.com 검색 → 결과 입력 → Phase 2에서 자동화 예정
  • 각 단계 승인/수정: 자동 초안 카드를 보고 고치거나 승인(승인=자동 다음 단계)

1키 콘텐츠 기획 — 11스텝 (PRD §3)

상품의 기능/특징/장점이 해결하는 문제를 역으로 도출해, 고객 구매 흐름에 배치하고 판매 논리를 만든다.
스텝입력 방식무엇을 / 어떻게산출물구현
— 상품👤 수동상품 정보 입력(처음 1회)ProductBrief완료
— 문제👤 수동고객이 겪는 핵심 문제 1줄 입력customer_problem완료
Step1🤖 자동내 아이템 일반화 (상품→카테고리→고객 문제 카테고리). 결정론ItemGeneralization완료
Step2🤖 자동기능/특징/장점 정리. LLM(상품+Step1)ItemFeatureBenefitMap완료
Step3🤖 자동카테고리 기능/특징/장점. LLM(Step1,2)CategoryFeatureBenefitMap완료
Step4🤖 자동해결하는 문제 도출. LLM(Step2,3 + 고객문제)ProblemDerivationMap완료
Step5🤖 자동현상/욕구/계획/행동/보상 퍼널. LLM(Step4)FunnelPlanningMap완료
Step6🤖 자동키콘텐츠 진입 단계 결정. LLM(Step5)KeyContentEntryDecision완료
Step7🤖 자동Viewtrap 검색축 5종 생성. 결정론(Step1~4)KeyContentSearchKeywordSet완료
Step8🔍 Viewtrap후보 검증(성과·기여·성장·채널가치). 현재 수동입력 → Phase2 자동ViewtrapValidation수동→자동예정
Step9🤖 자동판매 가능한 콘텐츠 산정. 결정론(Step8)viable candidates완료
Step10🤖 자동설득 구조(판매 논리) 작성. LLM(전체 누적)SalesLogicMap완료
Step11✅ 승인 👤제목/썸네일약속/도입방향/본문구조/CTA 확정. 사장님 수정+승인ApprovedKeyContentTopic완료
👤 상품 + 문제  →  🤖 Step1~7,9,10 자동초안  →  🔍 Step8 Viewtrap  →  ✅ Step11 승인  →  키콘텐츠 확정

2풀링 콘텐츠 기획 — 12스텝 (PRD §4)

키 콘텐츠를 볼 준비가 된 사람을 만드는 콘텐츠 포트폴리오 설계. 키콘텐츠 확정본을 자동 승계.
입력스텝(요약)방식구현
🤖 자동승계Step0 키콘텐츠 판매논리 불러오기 (앞 단계 결과 재사용 — 입력 없음)결정론함수 완료
🤖 자동Step1~4 준비된사람 정의·논리확장·문제축·콘텐츠유형(에버그린/데일리/시즌/히어로)LLM 순차순차체인 적용예정
🔍 ViewtrapStep5~8 기본검증·핫비디오 구조·노출확률·오래된 노다지(must_use)수동→자동함수 완료
🤖 자동Step9~11 점수화·키 연결성·소비자 5단계 커버리지결정론+LLM함수 완료
✅ 승인Step12 풀링 콘텐츠 세트 확정사장님 승인함수 완료
※ 풀링도 키콘텐츠와 동일하게 11스텝 순차 자동초안 패턴을 적용할 예정(현재 도메인 함수는 완료, UI 자동초안 배선이 다음).

3전략 패키지 → 영상까지 (PRD §5~6)

키+풀링 확정 후 제목/원고/영상으로. 거의 전부 자동 초안 + 승인.
단계입력 방식무엇을구현
전략 패키지🤖 자동 ✅키+풀링 통합 조립 + 일관성 검증함수 완료
제목/썸네일🤖 자동 ✅핫비디오 구조 반영 제목·썸네일 약속자산 있음
도입부 30초🤖 자동 ✅약속 회수 + 훅 구조자산 있음
본문 원고🤖 자동 ✅판매 논리 전개 원고 + QA자산 있음
내 말투 변환🤖 자동사장님 말투 프로필로 변환(논리 보존)자산 있음
CMO Brief🤖 자동 ✅AI Slide Factory로 넘길 기획서함수 완료
녹음 업로드👤 수동사장님 음성 파일 업로드완료
Slide Factory🤖 자동슬라이드 생성 → 영상 렌더LLM 연결됨
성과 재학습🤖 자동성과 → 다음 기획 반영루프 있음
⚠️ 점검 포인트 (사장님 결정 필요할 수 있는 것)
  • 상품 정보 입력 위치 — 지금은 프로젝트 생성 시 한 번. 이대로 OK? 아니면 키콘텐츠 단계에서 같이 받을까?
  • 고객 문제 외에 더 받을지 — 지금은 "고객 문제 1줄"만. 초안 품질을 위해 더 받을지(예: 가격/CTA), 아니면 그대로 최소 유지?
  • Viewtrap (Step8) — Phase 1은 수동(검색축 보고 사장님이 검색·입력). Phase 2에서 Playwright 자동(로그인 1회). 이 순서 OK?
  • 승인 단위 — 지금은 키콘텐츠 11스텝을 한 번에 초안→Step11에서 통합 승인. 아니면 중간(예: 문제도출, 퍼널)에서도 끊어 승인할지?
  • 속도 — 11스텝 LLM 순차라 ~3분. 독립 스텝 병렬화로 단축할지(품질 vs 속도)?
현재 구현: 키콘텐츠 11스텝 순차 자동초안 라이브 작동 확인(progress 8/8). 풀링 이하는 도메인 함수 완료, 자동초안 UI 배선 진행 예정. Viewtrap 자동화 = Phase 2.
