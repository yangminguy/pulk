0먼저 — 키 vs 풀링, 뭐가 다른가

키 콘텐츠는 "판매 논리가 직접 녹는" 콘텐츠다. 풀링 콘텐츠는 그 키를 볼 시청자를 채널로 끌어오는 입구다. 둘 다 같은 타깃(예: 작은 브랜드 대표)을 보지만, 역할이 다르다.

구분키 콘텐츠풀링 콘텐츠
목적상품 판매 논리를 직접 녹임시청자 유입 → 키로 브릿지
주제 범위내 아이템·문제 직결더 넓은 인접 주제 + 롱테일
검색축문제 / 아이템명 / 카테고리 / FBB키 주변 확장 주제 / 상위 고민 / 입문·방법(롱테일)
Viewtrap 핵심지표성과도·기여도 great + 조회수 5만+(터짐)성과도 + 노출확률 + 롱테일 꾸준한 수요
LLM 분류 질문① 판매논리 녹는가 ② 타깃이 보는가① 같은 타깃인가 ② 키로 브릿지되는가 ③ 꾸준 수요인가
핵심 차이: 키는 "터진 직판 주제"를 찾고, 풀링은 "꾸준히 유입되는 입구 주제"를 찾는다. 그래서 풀링은 조회수 기준이 더 유연하고, 노출확률·롱테일 꾸준함을 더 본다.
1풀링 전체 프로세스
1
키 콘텐츠 확정 (이미 됨)
판매 논리 + 타깃 + 키 주제가 정해진 상태에서 시작.
2
"키 보기 전에 뭘 볼까" 역설계
키를 볼 준비가 된 시청자가 그 전에 검색·시청하는 주제를 뽑는다. (상위 고민 · 인접 관심사 · 입문 방법)
3
풀링 검색축 생성 (3종)
① 상위 문제 ② 인접 주제 ③ 롱테일 에버그린. 문장으로 검색 OK.
4
Viewtrap 검색 + 필터
검색축마다 검색 → 성과도/노출확률 필터로 좁힘. (조회수 기준은 키보다 유연)
5
크롤링 → Sonnet 분류 (3기준)
제목·채널·썸네일로 같은 타깃 / 키 브릿지 / 꾸준 수요 판정.
6
풀링 주제 세트 산정
소비자 여정 5단계를 자연스럽게 덮도록 주제 묶음 구성.
7
각 풀링 → 키 브릿지 1문장
"이 주제로 들어온 시청자를 키 콘텐츠로 어떻게 연결할지" 한 문장.
2풀링 검색축 — 무엇을 검색하나 (키와 다른 점)

키가 "내 아이템·문제 직결 5종"이라면, 풀링은 시청자를 끌어오는 넓은 3종이다.

풀링 검색축뜻예 (인스타 자동화 툴 / 작은 브랜드 대표)
① 상위 문제키 문제보다 한 단계 넓은 고민"인스타 팔로워 안 늘어요", "브랜드 인지도 어떻게 올리지"
② 인접 주제같은 타깃의 다른 관심사"소상공인 마케팅", "브랜드 인스타 운영법"
③ 롱테일 에버그린꾸준히 검색되는 입문·방법"인스타 릴스 만드는 방법", "캔바로 게시물 만들기"

→ ③ 롱테일은 조회수 폭발보다 오래 꾸준히 유입되는 입구라, 노출확률·게시일 분산을 본다(must_use = 노다지 규칙).

3Viewtrap에서 무엇을 다르게 보나
지표키 콘텐츠풀링 콘텐츠
조회수5만+ 필수 (터짐)유연 — 꾸준하면 중간 조회수도 OK
성과도great (구독 대비 떡상)good 이상 (입구로 충분)
기여도높을수록 (주제 파워)참고
노출확률참고중요 — 알고리즘 유입 입구
게시일최근 트렌드분산 — 오래된 영상도 꾸준하면 에버그린 신호
4Sonnet 분류 — 풀링 3기준

크롤링한 각 영상을 Sonnet이 내 상품·키 콘텐츠 컨텍스트로 판정한다.

기준판단탈락 예
① 같은 타깃인가작은 브랜드 대표가 보는가 (쇼츠 수익화·일반 취미 제외)"릴스로 부업 월500" (수익화군)
② 키로 브릿지되는가이 주제로 들어온 시청자가 키(릴스 자동화)로 자연 연결되는가"인스타 감성사진 보정" (자동화로 안 이어짐)
③ 꾸준한 수요인가롱테일이면 일시 유행 아니라 지속 검색되는가"이번주 릴스 챌린지" (일회성)

통과 = 같은 타깃 + 키로 브릿지 + (롱테일이면) 꾸준 수요 → 풀링 주제 후보. 제목·썸네일을 근거로 사장님이 최종 선택.

5소비자 여정으로 묶기 — 풀링 세트의 완성

개별 주제를 모으는 게 아니라, 시청자가 키까지 오는 여정 전체를 덮도록 묶는다(Step11 커버리지 규칙).

① 문제 인식
"팔로워가 안 늘어"
② 정보 탐색
"브랜드 인스타 운영법"
③ 방법 학습
"릴스 만드는 방법"(롱테일)
④ 대안 비교
"직접 vs 자동화 도구"
⑤ 전환 (키)
"릴스 자동화로 다 해결" → 키 콘텐츠

→ 각 단계에 풀링 주제 1~2개씩. 비어있는 단계가 있으면 세트 미완(throw). 마지막에 키로 수렴.

6구체 예시 — 인스타 자동화 툴 (사장님 케이스)

🎬 키 콘텐츠 (확정됨)

"릴스 자동화" → 성과도·기여도 great, 조회수 5만+, 작은 브랜드 대표가 봄, 판매논리 녹음

🧲 풀링 콘텐츠 (이 키로 끌어올 입구들)

검색 → 크롤링 → Sonnet 분류 통과한 주제:

"인스타 팔로워 안 느는 진짜 이유" "소상공인 SNS 마케팅 시작하기" "릴스 기획부터 편집까지 한 번에" "혼자 브랜드 운영하는 대표의 하루"

→ 모두 작은 브랜드 대표가 보고(①), 릴스 자동화(키)로 연결되며(②), 꾸준히 검색됨(③). 이 입구들로 유입 → 키에서 판매 논리로 전환.

한 줄 요약: 키 = 터진 직판 주제(5만+·성과도 great), 풀링 = 꾸준한 입구 주제(노출확률·롱테일). 둘 다 Sonnet이 "같은 타깃인가 + (키는)판매논리 녹는가 / (풀링은)키로 브릿지되는가"를 제목·채널·썸네일로 판정한다.
