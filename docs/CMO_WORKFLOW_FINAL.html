사장님 기획대로 흐르는
CMO 영상 제작 워크플로우

비즈니스 PT 강의(세컨브레인 biz)의 방법론을 그대로 재현했습니다. 아래 흐름이 사장님 기획과 맞는지 확인해 주세요. 각 단계에 CMO가 하는 일, 사장님이 하는 일, 세컨브레인 활용, 승인 지점을 표시했습니다.

CMO가 함 사장님이 함 세컨브레인(강의) 활용 승인 게이트

전체 흐름 (사장님 기획)

상품 → 키 콘텐츠 → 풀링 → 썸네일 → 도입부 → 원고 → 녹음 → 영상

상품→ 키 콘텐츠→ 풀링 콘텐츠→ 썸네일 구성→ 원고 도입부→ 원고→ 녹음→ 영상
핵심 원칙(강의대로): 상품 장점이 아니라 고객 문제 상황에서 시작 · 역순 기획(판매 목표 먼저) · 풀링은 현상→욕구→계획→행동→보상 · 리서치는 사장님이 Viewtrap에서 직접 수행(CMO는 방법만 안내) · 도입부는 세컨브레인 인사이트 적용을 보고 승인. 레퍼런스 분석 단계는 제거했습니다.

단계별 상세

14단계 — 누가 무엇을 하나

1
PT 컨텍스트 로딩
business_pt_context_loading
CMO세컨브레인
CMO가 하는 일
세컨브레인 biz 강의 자료를 자동으로 읽어 이 사업의 기획 원칙을 정리합니다(최소 3소스).
결과
비즈니스 PT 컨텍스트 스냅샷. 이게 없으면 키 콘텐츠로 못 넘어갑니다.
2
상품 정의
product_defined
CMO
CMO가 하는 일
상품·타깃·고객 문제·목표를 정리. (상품 설명이 아니라 "어떤 문제를 푸는가"가 핵심)
결과
이 기준으로 키 콘텐츠 후보를 잡습니다.
3
키 콘텐츠 후보
key_content_ideation
CMO세컨브레인
CMO가 하는 일
세컨브레인 강의 방법론으로 키 콘텐츠 후보를 제시(확정 X).
강의 인사이트: "키 콘텐츠는 고객 문제 상황에서 시작 + 역순 기획(판매 목표 먼저 정하고 역으로)"
4
Viewtrap 키 리서치
viewtrap_key_research
CMO 안내사장님 수행
CMO가 하는 일
"이렇게 검색하세요" — 검색 키워드·방법 안내. (마케팅을 문제로 재정의, 경쟁사 벤치마킹)
사장님이 하는 일
Viewtrap에서 직접 리서치 → 결과(제목·조회수·URL·선택 이유)를 화면에 입력.
5
키 콘텐츠 승인 🔒
key_content_approval · gate
승인
CMO가 하는 일
Viewtrap 근거로 키 콘텐츠 1개를 추천.
🔒 사장님 승인 — 이 주제로 갈지 결정(승인/수정/다른 후보/보류).
6
풀링 콘텐츠 5세트
viewtrap_pulling_research → pulling_content_set_selection
CMO 안내사장님 수행세컨브레인
CMO가 하는 일
키 콘텐츠로 끌어올 풀링 콘텐츠 검색법 안내 → 모인 결과로 5개 세트 선별.
사장님이 하는 일
Viewtrap에서 풀링 후보 리서치 → 입력.
강의: 풀링은 현상 → 욕구 → 계획 → 행동 → 보상 중 한 단계만 담아도 됨. 각 콘텐츠가 키 콘텐츠로 이어지는 브릿지 필수.
7
풀링 세트 승인 🔒
pulling_content_set_approval · gate
승인
🔒 사장님 승인 — 풀링 5개 세트 + 키 콘텐츠 브릿지 확인 후 승인.
8
썸네일 구성
thumbnail_pattern_extraction
CMO세컨브레인
CMO가 하는 일
5세트 확정 후, 세컨브레인 후기 인사이트 + 확정한 5개 콘텐츠의 썸네일을 분석해 우리 주제 구조로 구성. (레퍼런스 영상 URL 단계 없음 — 제거됨)
9
원고 도입부 30초
intro_30s_analysis
CMO세컨브레인사장님 확인
CMO가 하는 일
세컨브레인 도입부/후킹 인사이트를 적용해 30초 도입부를 구성. "어떤 인사이트를 어떻게 적용했는지"를 표로 보여줍니다.
사장님이 하는 일
적용 인사이트 → 적용 방식을 보고 판단. (다음 게이트에서 승인)
강의: 도입부 0~5초 빌드업 문장으로 "왜 봐야 하는가" 제시 → 초반 후킹.
10
훅 승인 🔒
hook_draft_approval · gate
승인
🔒 사장님 승인 — 썸네일·제목·도입부(적용 인사이트 포함)를 보고 괜찮으면 승인 → Production으로.
11
원고 (장면 beat)
script_planning → script_draft
CMO 초안사장님 수정·확인
CMO가 하는 일
AI 슬라이드 팩토리 포맷(Hook→문제→전환→…→CTA 장면)으로 원고 초안 작성.
사장님이 하는 일
장면별로 헤드라인·대사·길이 직접 수정·확인 → "원고 저장".
🔒 원고 승인(script_approval) 후 → 팩토리로 전달 버튼 → 확정 원고가 Scene JSON으로 AI 슬라이드 팩토리에 전달·검증됩니다.
12
녹음
voice_recording
사장님 수행
사장님이 하는 일
확정 원고를 직접 녹음해 음성 파일 업로드. (TTS 아님 — 사장님 목소리)
13
영상 — 슬라이드 · 렌더 · QA 🔒
slide_deck → rendering → qa → video_qa_approval
CMO/팩토리QA 승인
CMO/팩토리

🔒 사장님 발행 승인 — 공개는 승인 후에만. 완료 시 성과 기록.

사장님 기획 대비 체크

이번에 사장님 지시대로 바꾼 것

✓
레퍼런스 분석 단계 제거 — 사장님: "레퍼런스 분석 단계가 빠져야 돼". 별도 단계 삭제, 썸네일은 세컨브레인 후기+5콘텐츠로.
✓
리서치는 사장님이 수행 — CMO가 Viewtrap 검색법만 안내, 사장님이 직접 리서치해서 자료 제공.
✓
세컨브레인(강의) 라이브 결선 — 키/풀링/썸네일/도입부/리서치 전 단계에 강의 인사이트 자동 반영.
✓
도입부 = 같이 하는 단계 — 어떤 인사이트를 어떻게 적용했는지 보여주고 사장님이 승인.
✓
원고 = 사장님이 수정·확인한 걸 전달 — 장면별 편집 → 확정 → AI 슬라이드 팩토리로 Scene JSON 전달(기존 팩토리 구조 재사용).
✓
흐름 정합 — 상품 → 키콘텐츠 → 풀링 → 썸네일 → 도입부 → 원고 → 녹음 → 영상.
현재 상태: 라이브 :13000에 배포 완료(컬렉션 생성됨). 라이브 E2E 27/27. 남은 것 = 실제 MP4 자동 렌더(현재는 사장님이 버튼/CLI로 발동).
확인 부탁: 위 14단계가 사장님 기획과 다른 부분이 있으면 알려주세요 — 단계 추가/제거/순서/승인 지점 조정 가능합니다.
