## 1. 발견된 문제 (근거 기반)

### 🔴 P1 — brandboy 최신 재설계가 미커밋·검증 미포함 (유실 위험)
오늘(07-28) 사장님 스토리보드 리뷰로 **문장단위→샷단위 브리프 전환 + 자가그래픽 30% 상한**이라는 재설계가 확정됐는데, 이 작업이 **untracked 스크립트 11개 + 미커밋 문서**로만 존재합니다. 커밋된 verify 16종에 커버리지가 없습니다.
- 실제 사고 이력: `build-shot-thumbs.ts --only`가 `_index.json`에서 **샷 61개를 조용히 삭제**(부분 실행이 병합을 안 함). `<audio>` id 누락 시 무음 렌더, 한글 폰트 `@font-face` 누락 등 문서화된 footgun 다수.
→ 지금 가장 큰 리스크는 코드 품질이 아니라 **오늘 만든 걸 잃는 것**입니다.

### 🔴 P2 — RAG 연동이 "조용한 무효화" 상태 (완료로 보이나 값을 안 줌)
pulk는 세컨브레인을 **spawn 트랜스포트**로 호출합니다(하드코딩 경로 `~/세컨 브레인`, 공백 포함). 문제 두 겹:
1. 트랜스포트는 경로/venv 없으면 **null 반환 = "graceful disable"** → 세컨브레인이 **조용히 사라져도** video-room은 그냥 스킵. 관측 불가.
2. 켜져 있어도 **값을 거의 안 줍니다.** 라이브 검증:
   - 쿼리 `"브랜드 영상 후킹 도입부 전략"` → `hits: 12`, `top_semantic: 0.944` **인데** LLM 심판 게이트가 `rejected: true`, 답변 `"아직 이것에 대해 쓴 적이 없어요"`.
   - 즉 4,010장 카드에서 마케팅 관련 쿼리가 0.94 유사도로 12개 걸려도 **빈손 반환**. 에이전트 맥락주입 용도엔 게이트가 과합니다.
→ PUL-17이 지적한 **"왜 안전하게 완료라 판단하나"** 공백이 RAG에서 그대로 재현. 연결은 "됨"인데 산출은 사실상 0, 그게 **안 보임**.

### 🟠 P3 — 시스템 파편화 (중복 2쌍 + 통합경로 2개)
- 세컨브레인이 **한글(성숙)·영문(반쪽) 2개.** 영문 `second-brain`의 유튜브 원자 707개는 한글 브레인이 이미 하는 ingest를 **중복**(둘 다 fastembed MiniLM multilingual). 영문쪽은 조회기가 아예 없어 지금은 죽은 코퍼스.
- 세컨브레인은 자체 **MCP 서버(도구 5개: search/ask/add/edit/list)**를 이미 제공하는데, pulk는 그걸 안 쓰고 **더 취약한 spawn 트랜스포트**를 씀. 통합 계약이 두 개.

### 🟠 P4 — pulk 메가 diff (한 이슈=한 목적 위반)
`feat/notion-gateway` 브랜치에 **수정 20 + untracked 약 10** 파일이 기능·문서·훅·백업 섞여 822줄 삽입, **미푸시**. 리뷰 불가. PUL-17이 지적한 바로 그 문제가 현재진행형.

### 🟡 P5 — 저가치 자동화 낭비
- `docs/cto-tool-catalog.md` 자가학습 잡이 매일 Anthropic/OpenAI 문서 **네비게이션 메뉴 쓰레기**("Loading… Loading…")를 긁어 저장. 토큰·디스크 낭비, 신호 0.
- `gh` CLI 미설치 → "GitHub 확인" 워크플로가 수동.

## 2. 업그레이드 개선안 (지금 쓰는 툴로, 최소 변경)

새 하네스 도입 없음. 이미 있는 것(git, fastembed, **세컨브레인 MCP 서버**, `verify-*.ts` 패턴)만으로 실행 가능.

### 🔴 지금
**A. brandboy 재설계 커밋 + 검증 커버.** untracked 11 스크립트 + 문서를 명명 브랜치에 커밋, `verify-visual-brief.ts`를 커밋된 16종 게이트에 편입 → 오늘 작업 유실 방지 + green 게이트 확보. (push는 Release 게이트/사장님 승인.)

**B. RAG 연동을 정직하게(health + fallback).** "조용한 null"을 **표면화**: video-room 턴마다 (1) 세컨브레인 도달 여부, (2) 인용 결과 반환 여부를 brief에 기록. 심판이 거절해도 **top-k 인용 원자는 맥락으로 반환**(검색≠Q&A — 맥락주입은 부분근거도 유용). 게이트를 retrieval 용도로 완화. → RAG의 "완료로 보임" 공백을 닫음.

### 🟠 다음
**C. 브레인 1개 + 통합경로 1개로 수렴.** 한글 `세컨 브레인`을 단일 정본으로. 영문 `second-brain`의 유튜브 원자 707개를 한글 브레인 ingest로 이관(cosine 자동 dedup 있음) 후 영문은 archive. pulk는 spawn 트랜스포트 대신 **세컨브레인 자체 MCP 서버**로 소비 → 공백경로 취약성 제거, 계약 하나로.

**D. pulk 메가 diff 분해.** `feat/notion-gateway`를 목적별 커밋(video-room 기능 / 문서 / 훅 / 백업)으로 쪼개 push. 이후 한 이슈=한 목적 유지.

### 🟡 정리
**E. 문서 스크레이퍼 폐기 + gh 설치.** cto-tool-catalog 자가스크레이프 중단(쓰레기 저장). 변경 감시가 필요하면 렌더된 네비 말고 실제 release-notes를 대상으로. `gh` 설치로 "GitHub 확인" 실동작화.
