영상 한 편을 만들 때 — "무슨 말을 할지"는 CMO가 끝까지 책임지고, "그걸 어떻게 화면으로 보여줄지"는 영상 공장(AI Slide)이 책임집니다. 둘은 기획서 한 장으로 일을 주고받습니다.
두 명의 일꾼
✍️

CMO / 스크립트 룸

= 마케팅 팀장 + 작가팀
제품·고객을 조사하고, 판매 논리를 설계하고, 내 말투로 된 대본까지 만들어 줍니다. 영상은 만들지 않습니다.

AI Slide 영상 공장

= 영상 편집실
기획서 + 내가 올린 녹음·얼굴 영상·화면을 받아, 각 장면을 어떤 화면으로 보여줄지 정하고 영상으로 렌더링합니다.
CMO가 해주는 일 (무슨 말을 할지)
1

정보 한 번에 받기

제품·고객·채널 상황을 폼으로 한 번에 수집. 부족한 칸만 따로 물어봅니다.

2

조사부터 한다 핵심

시장조사 · 고객 실제 말투 · 근거 검증 · "듣고 싶은 말인지" 점수. 점수 미달이면 원고 작성 못 넘어감.

"광고비는 쓰는데 손님이 안 늘어요" 같은 진짜 표현을 수집
3

전략·세트 설계

핵심 메시지·설득 순서·CTA 결정. 키 콘텐츠 1개 + 풀링 5개를 세트로 검증.

현상→욕구→계획→행동→보상 5단계가 세트 전체에 빠짐없는지 자동 점검
4

원고 작성 + 내 말투

도입부·본문·통합 후 내 말투로 변환(논리는 안 바꿈). 마지막에 5개 항목 QA 검수.

QA 실패 시 → 문제 난 단계만 다시 작업(전체 재작성 X)
5

기획서 한 장으로 넘기기

대본·근거·전략·필요 자료를 한 장에 묶어 영상 공장으로 전달. 여기서 CMO 일 끝.

영상 공장이 해주는 일 (어떻게 보여줄지)
A

기획서 검수

기획서가 제대로 왔는지 확인. CMO가 화면 종류를 미리 정해 넣으면 경고.

B

녹음·자료 정리

핸드폰 녹음의 잡음·울림·볼륨을 자동 보정 + 자막 생성. 얼굴/화면/이미지 자료 등록.

실제 영상 파일은 CMO가 아니라 사용자가 직접 올립니다
C

장면 결정 핵심

문장마다 "슬라이드 / 얼굴 영상 / 화면 녹화 / 이미지" 중 뭐가 제일 잘 이해되는지 알아서 선택.

자료 없으면 슬라이드로 대체 · 애매하면 "사람 검토 필요" 표시
D

영상 렌더링

실제 영상 파일 + 자막 + 챕터 + 품질 리포트 생성. CMO의 판매 논리·CTA는 안 바꿉니다.

0. 양쪽 두뇌 만들기 완료

CMO 쪽 조사·전략·원고·기획서 로직 + 영상 공장 쪽 장면결정·렌더 로직. 양쪽 다 코드·테스트 완료.

1

1. 코드 저장(커밋) 다음

지금까지 만든 걸 양쪽 저장소에 정식 저장. (현재 미저장 상태라 가장 먼저 해야 함)

2

2. CMO 실제 동작 확인 다음

실제 서버(NocoBase)를 켜고, "영상 생성" 버튼 → 기획서 1장이 진짜 DB에 만들어지는지 확인.

3

3. 두 시스템 연결 테스트 (가장 중요) 예정

CMO가 만든 기획서 1장을 영상 공장에 실제로 넣어 → 검수 → 장면결정 → 영상 직전(타임라인)까지 한 번 흘려보기. 여기서 둘이 진짜 맞물리는지 판가름.

4

4. 진짜 영상 1편 뽑기 예정

내 녹음·얼굴 영상·화면을 올리고, 공장이 실제 MP4를 렌더 → 결과물 품질 확인.

5

5. 화면 마감 예정

스크립트 룸 화면을 브라우저에서 검증, 카드 버튼이 실제 동작하게 연결, 완성된 영상 링크 표시.

6

6. 운영 다듬기 예정

기획서 자동 전달, 재작업(수정 요청) 흐름, 품질 점수 대시보드, 여러 영상 관리.

지금 상태: CMO·영상공장 양쪽 두뇌(로직)는 완성·검증됨(테스트 통과). 아직 둘을 실제로 한 번 연결해서 영상 1편을 끝까지 뽑아본 적은 없음 → 그게 다음 핵심 작업(3·4번).
