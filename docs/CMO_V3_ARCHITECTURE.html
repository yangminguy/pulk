왜 병렬이 안전한가 — 트랙 A(CTO/ACR 워커 강화)는 별도 repo agent_control_room_docs라 트랙 B(CMO 도메인, pulk)와 파일이 안 겹친다. 공유 자원은 ACR 실행 인프라 하나뿐 → 트랙 A는 워커 개선을 플래그 게이트(기본 off)로, 트랙 B는 안정 경로로 무관하게 진행. 트랙 B 내부 충돌은 통합 phase(Stage 3 직렬 병합)로 흡수.

D충돌 방지 3원칙 & 검증

  • 각 기능 마지막 = 통합 phase를 1급으로 명시 (산발 방지)
  • worktree 격리 + 공유 통합 파일은 마지막에 직렬 병합
