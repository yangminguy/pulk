Part B · 콘텐츠 발굴 워크플로우 (확정)
🔍발굴 = YouTube, 지표 검증 = Viewtrap

Viewtrap은 검색 한도가 있다. 그래서 발굴은 YouTube(무제한)에서, 지표 검증은 Viewtrap에서 분담한다.

YouTube

① 발굴 검색

  • API로 키워드/문장 검색
  • 한도 없음
  • 제목·썸네일·조회수
확장

② 1차 스크리닝

  • 검색결과 확장 지표
  • 기여도·성과도
  • 5만+ · Good+ 거름
Sonnet

③ 의도 분류

  • 같은 타깃인가
  • 판매논리 녹는가
  • (풀링)키 브릿지
Viewtrap

④ 노출확률 확인

  • 추려진 주제만
  • 뷰트랩 검색
  • 제목행 버튼 → 다건
산출

⑤ 주제 후보

  • 제목·썸네일 근거
  • 지표 실데이터
  • 사장님 선택

필터 기준: 조회수 5만+ · 성과도 good·great · 기여도 good·great · 노출확률 normal·good·great. 노출확률은 ④에서 뷰트랩 제목행 버튼으로 여러 영상을 한 번에 확인(watch 페이지 1건씩보다 효율적).

🧠Sonnet이 판단하는 것 (분류 엔진)
콘텐츠분류 질문
키 콘텐츠① 진짜 타깃(예: 작은 브랜드 대표)이 볼 주제인가 ② 판매 논리(문제→카테고리 FBB→카테고리→내 아이템 FBB로 해결→내 아이템)가 자연스럽게 녹는 주제인가
풀링 콘텐츠① 같은 타깃인가 ② 키 콘텐츠로 브릿지되는가 ③ (롱테일이면) 꾸준한 수요인가

검색 키워드(키): ① 문제 ② 아이템명 ③ 카테고리명 ④ 아이템 FBB ⑤ 카테고리 FBB · 문장 검색 OK, 타깃 수식어 결합 안 함.
