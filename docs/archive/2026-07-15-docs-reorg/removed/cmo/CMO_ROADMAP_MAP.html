F1렌더 잡 실제 push + QA + 업로드권장 다음
가장 가치 큰 다음 칸. Brief는 factory 인박스까지 실제 전달됨. 이제 submitJob으로 실 렌더 잡을 밀고 getRenderJobStatus 폴링 → QA → 업로드 초안까지 연결하면 영상이 실제로 나온다. buildSlideDeck이 brief 직접 참조하도록.
F2Viewtrap 실 스크래퍼구조적 한계
현재 reference-adapters는 어댑터 심만(수동 폴백). Viewtrap이 인메모리 인증+구글 OAuth 차단으로 영구 자동화 불가 확인 → 현실 모델 = run.mjs 1세션 1클릭 로그인 → 자동 검색·스크래핑. 검색결과 DOM 선택자 확정 1건 남음. (지금은 보류, 수동 입력으로 충분.)
F3성과 자동 수집현재 수동
R7 재학습 루프 코드·UI(PerformanceBoard)·인사이트 추출 완료. 단 성과 입력은 현재 수동. YouTube/외부 분석 API 연동으로 자동 수집하면 루프가 무인화된다.
