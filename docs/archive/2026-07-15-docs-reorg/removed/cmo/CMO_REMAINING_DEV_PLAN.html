1M2 · YouTube API 발굴 어댑터 미착수 · 기반, 먼저

발굴의 기반. 자격증명이 이미 발급되어 있어 바로 시작 가능.

  • services/youtube/에 검색·채널·analytics 클라이언트 신설
  • .credentials.json의 refresh_token으로 access_token 자동 갱신
  • 기능 3종: searchVideos(query) · getVideoStats(ids) · getChannelAnalytics(metrics, range)
검색 결과 + 조회수 5만+ 필터 + 디립다 채널 analytics(노출수·CTR 포함) 실수신
위치: services/youtube/ · 자격증명: services/youtube/.credentials.json (커밋 금지)

2M1 · Viewtrap/확장 크롤링 배선 미착수 · 지표 검증

2026-06-10 실증한 CDP 크롤링(/tmp/cdp-*.mjs)을 정식 코드로 이관.

  • 흐름: 주제 추려지면 → Viewtrap 검색창 자동입력 → 제목행 노출확률 버튼 클릭 → 기여도·성과도·노출확률 다건 크롤링
  • 필터: 조회수 5만+ · 성과도 good·great · 기여도 good·great · 노출확률 normal·good·great
  • reference-adapters.ts에 scraper 주입(심 → 실 어댑터) → 키 콘텐츠 Step8(buildViewtrapValidation) 자동 채움
CDP 운전(로그인 크롬, 복사 프로필 ~/chrome-cdp) · 로그인 탭 새로고침 금지 · 실패 시 수동 폴백 유지
위치: services/youtube/ 또는 apps/founder-ui/e2e/viewtrap/

3M3 · Sonnet 의도 분류 엔진 미착수 · 핵심 "생각"

크롤링 결과를 상품·타깃 컨텍스트로 분류. 모델 = Claude Sonnet 고정.

  • 키 콘텐츠 판단: ① 타깃이 볼 주제인가 ② 판매논리(문제→카테고리FBB→카테고리→아이템FBB→아이템)가 녹는가
  • 풀링 판단: ① 같은 타깃인가 ② 키로 브릿지되는가 ③ (롱테일) 꾸준 수요인가
  • 출력: 적합/모호/부적합 — 적합 + 성과좋음 = 후보 근거
위치: l5-core/cmo-strategy 또는 video-room 신규

4M1~M3 통합 미착수

키 Step8 + 풀링 Step5/8에 발굴 → 크롤링 → 분류를 연결. 후보의 "viewtrap 선정이유"를 LLM 추측에서 실데이터 근거로 교체.

🎬 산출 마감 트랙

5M4 · 영상 제작 파이프라인 잔여 R6 잔여 — Brief 전달까지 완료

Brief는 실 factory 인박스(briefs/<slug>.json)까지 전달됨. 렌더 이후 구간만 남음.

  • buildSlideDeck이 brief 직접 참조 → submitJob 렌더 push → getRenderJobStatus 폴링 → 영상 QA → 업로드 초안
위치: slide-deck-generator.ts · video-factory-transport.ts

🔁 재학습 무인화 트랙

6M5 · 성과 자동 수집 R7 잔여 — 코드·UI 완료, 입력만 수동

발급된 OAuth로 디립다 채널 analytics를 자동 수집해 수동 입력을 대체.

  • 업로드 영상 성과(노출·CTR·시청지속) → performance-ingestion.ts → completion-insight-extraction.ts → 다음 기획 반영
  • M2의 analytics 클라이언트 재사용
M2 완료 (analytics 클라이언트)

🛠️ 운영·개선 트랙 (병행 가능)

7M6 · 텔레그램 알림 실작동 병행

TELEGRAM_BOT_TOKEN/CHAT_ID를 NocoBase launchd plist에 주입 + kickstart. 코드는 이미 graceful 완료 상태.

7M7 · 속도 최적화 병행

키 초안 LLM 순차 ~178~218초 (step2‖step3 병렬은 적용됨). 추가 독립 스텝 병렬화 + 모델/프롬프트 튜닝 — 품질 회귀 없이.

7M8 · 라이브 HTTP E2E + 정리 병행

NocoBase 실 E2E(generate→send→briefs/ 확인) + /tmp/cdp-*.mjs·데모 산출물 정리 + 미커밋 hunk 분리.
