# 11 · 사용자 컨설팅 기록 (개인 컨텍스트)

> **목적**: 사용자(양원민)가 실제 비즈니스 PT 컨설팅을 받으며 남긴 주차별 기록(2~6주차)을 정리한 문서. 앞선 방법론 문서(00~10)가 "일반 이론"이라면, 이 문서는 **이 사용자에게만 해당하는 실제 상황·결정·과제·고민**이다.
> **원천**: 양원민 Documentation의 「비즈니스 pt N주차 컨설팅」 메모 (2·3·4·5·6주차). ※ 1주차·7주차는 별도 컨설팅 메모가 없음(7주차 내용은 원고 작성 문서에 포함).
> **관련 문서**: 00_INDEX_사용안내.md, 02_아이템_상품_선정.md, 04_키콘텐츠_기획.md, 05_풀링콘텐츠_설계.md, 07_제목_디벨롭.md, 08_썸네일_디벨롭.md
> **AI 사용 지침**: 사용자를 상담할 때 이 문서를 **최우선 컨텍스트**로 삼는다. 00~10의 이론을 **이 사용자의 상품·타겟·현재 단계·블로커에 맞춰** 적용하라. 아래 "현재 상태" 값은 시점에 따라 바뀔 수 있으므로, 최신 대화 내용이 있으면 그것을 우선한다.

## 사용자 비즈니스 프로파일 (기록에서 종합)

- **판매 아이템(방향)**: AI/마케팅 자동화 서비스. 컨설팅을 거치며 범위를 좁혀 **"인스타그램 자동화 마케팅 전문"**으로 뾰족하게 포지셔닝하는 방향으로 정리됨. 인스타·메타·쓰레드 자동화, 광고 + 콘텐츠 제작을 뾰족하게 가져감. (별도로 쿠팡 파트너스 채널 2개도 운영 예정 — 이건 자동화 대상.)
- **타겟 고객**: **대표님(의사결정권자)**, **1인 사업자·작은 브랜드(구성원 5~6명 규모)**, 생존/성장을 위해 마케팅을 직접 고민하는 사람, "인스타로 매출 올리고 싶은 사람 / 돈 벌고 싶은 사람".
- **USP(차별화) 가설**: 대형 마케팅 대행사는 컨트롤 영역이 넓어 **디테일한 성과 관리가 약하다** → "이것만큼은 내가 해줄게"라는 **디테일 하나**로 파고든다. 사례를 **내 관점(인사이트)으로 전환**해 전달 → 팬덤화.
- **키 콘텐츠 방향(가설)**: 해외 AI 마케팅 성공 사례, "인스타그램 자동화"(거의 다 키로 활용 가능하다고 판단), "연매출 ~억 낸 마케팅 운영 방법", 사업 관점의 디테일한 인스타 마케팅.
- **풀링 콘텐츠 방향(가설)**: "콘텐츠 마케팅이 (내 상품이 해결하는 문제라서) 좋다"는 것을 이해하게 만드는 콘텐츠 → 키 콘텐츠로 연결.
- **현재 최대 블로커(5주차 이후)**: **풀링 주제 찾기가 어렵다.** 인스타그램을 세부적으로 나눠 마케팅하는 채널이 (벤치마킹할 만큼) 없어서 어떤 주제를 잡을지 모호함. 다만 노출 확률 높은 콘텐츠를 보면 "마케팅 자동화"가 많아서, 오히려 그게 본인이 할 만한 콘텐츠일 수 있다고 봄.
- **실행/스킬 상태**: 숏츠·미드폼 실제 제작 및 업로드 경험 있음, 썸끝·원끝 훈련 중, 제목/썸네일 디벨롭·핫비디오 7단계 연습 중. 업로드 시 각 영상을 풀링/키로 분류·저장하는 습관 형성 중.

## 2주차 컨설팅 — 과제 잘하는 법 · 수익화 기획 · USP

**핵심 논의**
- **썸끝(썸네일 끝장내기) 키워드 찾기**: 좋은 썸네일에서 자주 쓰는 키워드를 보고 판단하고, 그 키워드로 다시 썸끝을 돌린다. 이 작업은 키워드 확장·시장 확장에도 유용하다.
- **원끝(원고 끝장내기, 도입부 30초 받아적기)**: 도입부 30초를 그대로 받아적고, 5개 원끝 중 가장 후킹된 것을 고른 뒤 **"내가 왜 후킹됐지?"**를 복기한다. (예: 전체 과정의 흩어진 조각을 붙여놨구나.) 대비되는 구조·반복 구조를 찾는다. 내가 왜 끌렸는지 복기하는 것이 핵심.
- **분석 과정**: 좋은 썸네일을 나열해 공통점·키워드·문장(방향성 긍/부정, 이미지 특성 등)을 찾는다.
- **영상 수집**: 뷰트랩에서 폴더를 만들어 내가 후킹된 영상들을 수집해두고 재료로 쓴다.

**수익화 기획 — 스스로 던져야 할 질문**
1. 다른 업체들은 어떻게(얼마에) 비용을 받고 있는가?
2. 내 고객이 볼 만한 채널은 무엇인가?
3. 이 정도로도 사람들이 모인다고? (시장 존재 확인)
4. **내가 이 사람보다 뭘 더 잘할 수 있을까?**
5. **사람들은 무엇 때문에 구매하고 있지?**
6. **내가 뭘 더 줄 수 있을까?**

**과제(To-do)**
1. 2주차 강의 듣기.
2. 구매자 니즈 확인 — 사람들이 뭘 원하고 뭐가 안 되고 있는지.
3. 실제 판매자들의 수준 확인 → 내 USP 찾기. (해당 주제 채널들을 실제 시청하며 강점·아쉬운 점 분석, 에이전트 팀 기반 판매자는 어떤 콘텐츠를 파는지 확인, 시장에서 잘되는 강의·채널 찾아 "내가 비집고 들어갈 곳"을 확인, 후기를 통해 대표들이 뭐가 불편한지 보기. 2주차 시장성 검토 병행.)
4. **정한 아이템 기반으로 타겟이 볼 만한 숏츠 1개 제작.**
5. **실제로 업로드해보기.**

**Q&A**
- **기여도·성과도 측정법**: 기여도 = 그동안의 평균 조회수보다 높은지 / 성과도 = 구독자 수보다 더 많이 봤는지.
- **샘플 영상 사용법**: 무료 스톡 영상 사이트 이용, 출처만 밝히면 사용 가능. 저장이 안 되는 영상은 못 씀. 업로드 시 (저작권 관련) 메시지가 뜰 수 있음.

## 3주차 컨설팅 — 키워드 확장 · 풀링/키 설계 · 콘텐츠의 본질

**핵심 논의**
- 마케팅이라는 "상품"을 "문제"로 변환하고, 그 문제를 확장해 풀링 콘텐츠를 찾아내는 결을 이해해야 한다. 문제는 욕구의 실체화 → **어떻게 욕구를 건드릴까**가 관건.
- 전문성이 없어도 서비스하고 싶다면, 돈 잘 버는 사람들("월급쟁이 부자들"처럼)을 데려와 레버리지할 수 있다. (쿠팡 파트너스 채널까지 2개 운영하되 자동화 예정.)

**키워드 확장 방법**
- 유튜브에 검색해 영상에서 쓰는 키워드를 뽑아 확장한다. 예: 마케팅 자동화 → 업무 자동화 → AI 에이전트 → …
- 나와 같은 서비스를 운영하는 곳은 어떤 전략인가? ("그로스 파트너" 등 검색.) 잘하는 마케팅 대행사의 리뷰가 진짜 맞을까 의심해보기.
- 대행사들은 컨트롤 영역이 넓어 세세한 관리가 어렵다 → "이것만큼은 내가 해줄게"라는 **디테일한 하나**가 필요.

**내가 설계한 풀링·키 콘텐츠 유의점**
1. 경계를 맞추는 과정 필요 → 대표님들이 "더 보고 싶은 결"로 만든다.
2. 해외에서 대표님들이 트렌드·기능을 소개하는 채널, 관심 있어 하는 기능을 접목해 성장한 작은 브랜드 사례.
- 항상 **"대표님들이 이 영상을 볼까?"**를 중심에 둔다. → 이 판단에서 얼굴 등장 유무도 결정된다.

**인사이트 (본인 강조)**
- 키 = "해외 AI 성공"이라면, **풀링은 "콘텐츠 마케팅이 좋다(=내 상품이 해결하는 문제가 콘텐츠 마케팅)"는 것을 이해하도록 선별**해야 키 콘텐츠를 보게 된다. 키 콘텐츠는 "내 상품이 좋다"를 이해시키도록 선별. **결론이 좋은 콘텐츠로 끝날 수 있는 콘텐츠**를 고민해야 한다.

**콘텐츠의 본질**
- "이 영상을 보고 얻어갈 게 뭐야?"를 분명히. **결론부터 말한다.** 이 영상이 뭘 중요하게 생각하는지 처음부터 이야기한다.

**과제(To-do)**
1. 여러 키워드를 뷰트랩에 검색해 실제 성과 좋았던·대표님들이 보기 좋았던 것 찾기.
2. 썸끝·원끝에서 잘되는 것들 만들어보기.
3. 미드폼·썸네일 만들어보며 실력 늘리기.
4. 원끝에서 좋았던 도입부 적용해보기.
5. "이 주제로 시작해 결론이 키 콘텐츠를 보고 싶게 만들려면?"을 3주차 강의 듣고 만들기.
- (경쟁사 리서치) 잘 파는 사람이 얼마나 많은지, 이들은 USP를 어떻게 설명하는지, 이들의 디벨롭을 본다. 꼭 마음에 들었던 것은 반드시 적용해볼 것.

## 4주차 컨설팅 — 콘텐츠 관리 · 원고 분석 · 제작 순서

**핵심 논의**
- (계정 관리) 아동용 아님 설정 후 업로드. 앞으로 영상 올릴 때 **반드시 풀링/키 콘텐츠로 분류·저장**. 비즈니스 PT → "콘텐츠 관리" 관점.
- 5가지 단계 안에서 주제 선정은 됐으니, 이제 **"그걸 왜 볼까?"**를 고민한다. 주제를 왜 보고 싶은지에 집중.

**원고 분석할 때**
- 원고의 각 문장이 "사람들을 더 보게 만들었는지" 그 **표현**을 봐야 한다.
- 대표님들이 더 공감할 만한, 콘텐츠 제작 시 있었던 일들. "이 영상을 보면 A부터 Z까지 다 알려주겠다"는 느낌. 개념부터 세팅하고 분석해준다.

**제작 순서(중요)**
- **주제 선택 → 썸네일 → 도입부 → 원고** 순서로 간다.
- 썸끝으로 썸네일 만들고, 원끝으로 (썸끝 구조에서 이어온) 유저를 도입시키고 → 욕구를 충족시키고 → 계획을 제공하면서 → 내 상품을 이야기한다.
- 내가 만족할 수준의 콘텐츠를 만들어야 그걸 기반으로 피드백을 받는 의미가 생긴다. **최대한 많이 적용해서 만들어보자.**

## 5주차 컨설팅 — 풀링 주제 찾기 · 타겟/포지셔닝 좁히기

**핵심 논의**
- **풀링 콘텐츠 주제 찾는 법**: ①기여도·성과도 ②구독자 낮은 순(채널 가치 낮은데 뜨는 영상) ③떴는데 천천히 올라가는 영상 찾기. (광고 비용 보는 사람들이 뭘 하는지도 확인.)
- **타겟 구체화**: 1인 창업·작은 브랜드(5~6명)를 골라야 한다. "그로스(성장)를 위해 살아남으려고 볼 정도로" **뾰족하게**, 디테일한 방법을 알려주는 콘텐츠.
- (벤치마킹) "광고 해결"류 남의 채널: 구체적 사례, 광고 돌릴 때 생기는 문제점, 콘텐츠 제작을 혼자 따라 할 수 있을 만큼 구체적으로. 어떤 콘텐츠가 인기인지, 업로드는 어떻게 하는지 프로세스를 본다.
- "브랜드 총정리"류는 전체 브랜드 컨설팅용으로 쓰고, 콘텐츠는 **더 뾰족하게**.
- **리서치 행동**: 1인 사업자 카페·채널 구독·단톡방에 들어가 콘텐츠 만들 때의 고민을 확인하고 그 고민 기반으로 제작. ("마케터 은진" 등에서 뜬 영상을 할 수 있는 주제로 가져오기.) 항상 **"우리 타겟은 어떤 영상을 볼까? 무엇에 관심 있을까?"**가 본질.
- **플랫폼 선택**: 인스타·메타·쓰레드 자동화. 여러 개를 동시에 하면 전문성이 떨어져 보이니 각각 운영하기 좋다. **인스타만 가져가는 게 좋을 듯.** ("AI 마케팅 대표 채널"은 광고만 돌리는 방향.)
- **시청자 타겟이 뚜렷할수록 채널 크기가 정해진다.** 타겟의 욕심이 뭘까 고민. 인스타·유튜브 대행이 많다면 시장은 있는 것. "인스타 범주 안에서 사업을 운영하는 방법", "사업 관점에서 인스타 마케팅 하는 법" 같은 디테일.
- **키/풀링 판단**: "인스타 자동화" 주제는 거의 다 **키로 활용 가능**. "인스타 매출 올리고 싶은/돈 벌고 싶은 사람"도 키 가능. **풀링은 키로 활용될 수 있어야 한다 → 풀링을 키에 접목**시켜본다.

**과제(To-do)**
- 영상을 보고 주제가 뭔지·어떤 타겟이 볼지·왜 클릭했는지 고민.
- 대행사 광고 세팅법을 보고 "내 상품으로 어떻게 떨어지게(전환) 만들지" 고민.
- **풀링 5개 만들어보고, 그중 접목해 풀링 1개 만들기.**

**5주차 컨설팅 이후 (본인 회고)**
- 지금 **풀링 주제 찾기가 참 어렵다.** 인스타그램을 구체적·세부적으로 나눠 마케팅하는 채널이 없어서, 인스타라는 집합 안에서 어떤 주제를 잡을지 모르겠다.
- 노출 확률 높은 콘텐츠를 보면 "마케팅 자동화"가 많다 → 오히려 그게 내가 할 만한 콘텐츠일지도.
- 잠정 포지셔닝: **"인스타 자동화 마케팅 전문".**

## 6주차 컨설팅 — 제목 디벨롭 · 핫비디오 7단계 · 사례의 인사이트화

**핵심 논의 — 제목/풀링 방향 평가**
- 풀링 콘텐츠 방향을 틀었는데, 객관적으로 평가받기. 기준은 항상 **"그 영상을 대표님이 볼까?"** → 대표님들이 마케팅할 때 고민하는 걸 주제로 가져온다.
- "이상한 마케팅" 같은 타겟이 볼 만한 걸 뷰트랩에 검색. 예: "인스타그램에서 매력적으로 브랜딩 하는 방법"을 그대로 뷰트랩에 넣어 찾기.
- (참고 사례) "캠핑 마케팅 / 다른 캠핑장은 안 봤으면 좋겠어요" 같은 **리뷰형 채널**, 네이버 광고에서 영감을 받아 "인스타 게시물 광고"로 확장.
- **주제 찾는 절차**: ①내 타겟이 볼 만한 채널 먼저 찾기(네이버·메타 등 어느 플랫폼이든) ②거기서 내 용어에 맞게 바꾸기 ③주제 될 만한 거 찾아 다시 넣기 ④"마케팅 대행"이라 검색해 잘된 채널 기반 확인. → **대표님들이 볼 만한 채널인지가 제일 중요.**

**핫비디오 썸네일 (7단계 디벨롭)**
- 구조를 분석한다. 예: "거실 넓게 쓰려면 이렇게 배치하지 마세요" = 타겟이 원하는 모습(거실 넓게) + 그걸 달성하려면 이렇게 하지 마세요. → "인스타로 매출 올리려면 이렇게 릴스 만들지 마세요"로 디벨롭.
- 크로스(조합)는 어디서 본 듯하지만, 핫비디오는 **디벨롭으로 끝난다.** 이 문구가 뭘 의미하는지, 누가 왜 보는지 생각하고 구조를 뜯어 활용한다. **7단계는 완전히 새로운 걸 가져와야 한다.**
- 디벨롭 다 해보고 **다시 생각한다: 더 후킹되게 만들었나? 왜 후킹된 거지?** 아니면 되돌아간다.
- 내 방법대로 남이 해본 결과물을 가져와 실제 사례로 보여주며 적용한다.

**영상 리뷰 — 사례의 인사이트화**
- "작지만 큰돈 버는 브랜드들은 ~한다"며 그 사례들을 보여준다. 사례를 많이 공부·분석하는 것이 중요.
- 그 사례들을 **나만의 인사이트로 전환**해 내 관점으로 말해준다. → **이게 팬덤이 된다.** 반드시 내 관점으로 전환.
- 해외 채널(인터뷰 채널, "자기계발" 검색 등)을 찾아 어디서 소재를 가져오는지 확인.
- **사례 적용은 하나의 후킹 정도로 생각.** 꼭 인스타로 성공한 사례가 아니어도 됨 — **성공 방정식을 적용**하면 된다.

## 컨설팅 적용 포인트 (AI 사용 지침)

- **이 사용자의 확정 사실을 기억하고 반복 질문하지 말 것**: 상품=인스타/AI 마케팅 자동화(→인스타 자동화 마케팅 전문으로 좁힘), 타겟=대표님·1인 사업자·작은 브랜드. 이미 정해진 것을 다시 처음부터 정하게 하지 말고, 그 위에서 다음 단계를 조언한다.
- **현재 블로커에 초점**: 사용자의 최대 난점은 **풀링 주제 찾기**다. 상담 시 05(풀링콘텐츠 설계)·07(제목 디벨롭)의 방법을 이 맥락에 적용해, "인스타 자동화/마케팅 자동화" 안에서 **키로 접목 가능한 풀링 주제**를 구체적으로 뽑도록 돕는다. (5주차 과제: 풀링 5개→접목 1개.)
- **판단 기준 문장 고정**: 새 주제·제목·썸네일을 평가할 때 항상 **"이걸 대표님(1인 사업자)이 볼까?"**로 되묻는다.
- **USP 강화**: 대행사의 약점(디테일 관리 부족)을 파고드는 "디테일 하나", 그리고 **사례를 사용자 관점의 인사이트로 전환(팬덤화)**하는 방향을 계속 상기시킨다.
- **제작 순서 준수**: 주제 → 썸네일(썸끝) → 도입부(원끝) → 원고. 사용자가 순서를 건너뛰면 되돌린다.
- **행동 습관 점검**: 업로드하는 영상마다 풀링/키 분류·저장, 후킹된 영상 뷰트랩 폴더 수집, "왜 후킹됐는지" 복기가 이루어지고 있는지 확인한다.
- **톤**: 사용자는 이미 실행·개념 이해 수준이 높다. 기초 설명보다 **구체적 주제/제목 후보, 경쟁사 분석 관점, 다음 실험**을 제시하는 방향으로 상담한다.
