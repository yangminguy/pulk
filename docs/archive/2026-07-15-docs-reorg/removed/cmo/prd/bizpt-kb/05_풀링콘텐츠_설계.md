# 풀링 콘텐츠 설계

> **목적**: 시청자를 잠재 소비자(문제를 가진 사람)로 바꿔 키 콘텐츠 앞으로 데려오는 풀링 콘텐츠의 정의·유형·준비 절차·논리적 확장 방법을 정의한다.
> **원천**: 비즈니스 PT 강의 4주차.
> **관련 문서**: 00_INDEX_사용안내.md, 03_소비자행동_퍼널.md, 06_뷰트랩_리서치_가치판단.md, 07_제목_디벨롭.md.

## 핵심 요약 (TL;DR)
- **풀링 콘텐츠 = 시청자를 잠재 소비자로 바꾸는 입구 콘텐츠.** 출발점은 항상 **문제 인식**이며, 목적은 키 콘텐츠를 볼 만한 사람을 모으는 것(조회수 생성).
- **키 콘텐츠 = 잠재 소비자를 실제 소비자로 바꾸는 구매 전환 콘텐츠.** 두 콘텐츠는 질문 하나로 구분된다: **"그거 보면 살 것 같아?"** → "그렇다" = 키 / "키 콘텐츠를 볼 것 같아?"의 후보군을 데려온다 = 풀링.
- 풀링이 필요한 이유: **기본 논리(키)만으로는 고객 풀이 너무 작아 채널이 운영되지 않는다.** 잠재고객을 넓게 끌어와 내 논리로 이해시켜야 한다.
- **풀링 4유형**: 에버그린 / 시즌성 / 데일리 / 히어로. 운영 전략은 **에버그린·데일리로 바닥을 깔고, 그 결에 맞는 시즌성·히어로를 찍는다.**
- 콘텐츠는 **소비자 행동 퍼널(현상 → 욕구 → 계획 → 행동 → 보상)** 위에 배치한다. 계획 단계엔 **상품군**, 행동·보상 단계엔 **내 특정 상품**이 온다.
- **논리적 확장 = 키워드를 넓히는 게 아니라, 내 상품 → 기능 → 고객 문제 → 그 문제를 가진 사람 → 그 사람이 볼 콘텐츠 주제로 확장하는 것.** 핵심은 "우리 제품의 기특장(기능·특징·장점)으로 어떤 문제를 인식시킬 것인가".
- 준비 절차는 **8단계(+무위의 단계)**. 순서 원칙: **1~5단계를 먼저 마스터**, 매출 **500만 원 초과 시 6단계**.
- 뷰트랩 조작 세부(지표·필터·정렬)는 문서 06에 위임한다. 이 문서는 설계 논리에 필요한 만큼만 언급한다.

## 1. 풀링 콘텐츠란 무엇인가

**정의:** 풀링 콘텐츠는 시청자를 **잠재적 소비자**로 바꾸는 콘텐츠다. 키 콘텐츠를 볼 만한 사람을 모으는 입구 역할을 하며, 출발점은 **문제 인식**이다. 조회수를 만드는 콘텐츠다.

**정의:** 키 콘텐츠는 잠재적 소비자를 **실제 소비자**로 바꾸는 콘텐츠다. 구매 전환을 담당하는, 퍼널에서 저 아래 단계의 콘텐츠다.

수익화 구조는 **풀링 → 키 → 랜딩(수익화)** 순서로 흐른다. 각 콘텐츠가 시청자의 상태를 한 단계씩 앞으로 옮긴다.

`풀링 → 키 → 랜딩(수익화)`

### 두 콘텐츠의 구분 규칙

**규칙:** 두 콘텐츠는 **"그거 보면 살 것 같아?"** 라는 질문 하나로 구분한다.

- **키 콘텐츠**: 그거 보면 **살 것 같아?** → "그렇다"고 답할 수 있는 콘텐츠.
- **풀링 콘텐츠**: 그거 보면 **키 콘텐츠를 볼 것 같아?** → (즉, "살 것 같아"라고 답할 수 있는) 후보군을 데려오는 콘텐츠.

**규칙:** 풀링은 키 콘텐츠를 볼 만한 사람을 데려오는 것이므로, 반드시 **문제 인식의 결에 맞는 콘텐츠**가 나와야 한다. 우리 제품의 기특장(기능·특징·장점)에서 출발해, 그 기능이 해결하는 문제를 인식할 만한 사람을 끌어온다.

> **이번 주차 핵심 한 문장:** "우리 제품의 기특장(기능·특징·장점)을 기반으로, 시청자에게 어떤 문제를 인식시킬 것인가."

> **예시) 소니 녹음기** — 소니 제품 → 녹음기 → 음성 저장 → "소리를 기억하고 싶은" 사람, 그리고 **성적 올리는 방법**. 성적을 올리는 방법은 학생들이 공감한다. 그러니 "공부 열심히 하는 학생"을 풀링으로 데려오면 된다.

> **예시) 시스템 에어컨** — 시스템 에어컨 설치 → 시스템 에어컨 → 공간 확보·공기 청정·기온·냉방 → **공간 부족 문제, 거주자 컨디션, 불쾌감 낮추기** → 인테리어 등으로 확장. 제품 기능이 건드리는 문제(공간·컨디션·불쾌)를 인식할 사람을 데려온다.

## 2. 풀링 콘텐츠가 필요한 이유

**규칙:** 기본 논리(키 콘텐츠)로 끌고 올 사람을 모으는 게 목적이다. 그런데 **기본 논리만으로는 채널이 운영되지 않는다.** 그 논리에 정확히 해당하는 고객 풀 자체가 너무 작을 수 있기 때문이다.

> **예시) 왜 키 콘텐츠만으로는 안 되나** — 소니 제품으로만 콘텐츠를 만든다면 "소니 제품의 역사, 기능, 특징" 식으로 갈 수밖에 없다. 그런데 이런 콘텐츠는 **보는 시청자 자체가 작다.** 그래서 잠재 고객을 넓게 끌어오고, 그 고객이 내 논리대로 이해할 수 있게 만드는 과정이 중요하다.

### 소비자 행동 퍼널 위에 콘텐츠를 배치한다

`현상 → 욕구 → 계획 → 행동 → 보상`

**규칙:** 이 흐름을 세트로 볼 때 **계획 단계에는 상품군**이 담기고, **행동·보상 단계는 내 특정 상품**으로 넘어와야 한다.

기획을 시작할 때는 **내가 목표로 하는 목표 매출**, 그리고 그 매출 규모에 맞는 사람들이 지금 뷰트랩에 남기는 데이터를 함께 보고 확인한다.

## 3. 풀링 콘텐츠 4유형 (깔아 둘 콘텐츠 vs 찍을 콘텐츠)

두 축으로 나눈다: **트래픽 지속성**(에버그린 vs 시즌성)과 **투입 비용**(데일리 vs 히어로).

| 유형 | 정의 | 트래픽 특성 | 투입비용 | 예시·비고 |
|---|---|---|---|---|
| **에버그린** | 상록수처럼 꾸준한 선호가 있어 계속 트래픽이 발생하는 콘텐츠. | 계속 꾸준하게 트래픽 발생. 유통기한이 길다. | (지속형) | 오래됐는데도 노출 확률이 높은 "클래식" 주제(4단계 참조). 바닥에 깔아 두면 채널이 오래간다. |
| **시즌성** | 일시적으로(또는 일정 기간) 폭발적 트래픽이 발생하는 콘텐츠. | 시즌이 끝나면 트래픽이 확 죽고, 언제 홈 화면에 노출될지 알 수 없다. | (폭발형) | 에버그린·데일리의 결에 맞춰 찍는다. |
| **데일리** | 투입 시간과 제작 비용이 **적은** 콘텐츠. | (비용 축 기준) | **적음** | 자주 깔아 두는 축. |
| **히어로(특집)** | 투입 시간과 제작 비용이 **큰** 콘텐츠. | (비용 축 기준) | **큼** | 결에 맞을 때 한 방으로 찍는다. |

**규칙 (운영 전략):** **에버그린·데일리 콘텐츠를 중심으로 깔아 놓는다.** 그리고 그 결에 맞는 시즌성·히어로를 찍는다. 유통기한이 긴 상품(에버그린)으로 바닥을 깔아 두어야 채널이 오래간다.

### 홈 화면 노출이 떡상을 결정한다

**규칙:** **홈 화면 노출에 따라 떡상이 결정된다.** 알고리즘의 **80%는 탐색**이고, 그 탐색의 **90%는 홈**에서 일어난다.

`알고리즘 → 탐색 80% → 홈 90%`

홈 화면에서 **선택의 기준이 되는 것은 썸네일**이다. 상품으로부터 정한 내 주제에서, 홈 화면에 노출되어 선택받은 썸네일을 보면 "나도 이렇게 하면? → 내 채널에 성장이 온다"는 판단이 선다.

> **주의:** 썸네일은 **똑같이 하면 안 되고 더 잘해야 한다.** 이미 선택받은 썸네일을 그대로 베끼는 것으로는 부족하다.

### 노출 확률과 기여도 — 두 지표를 분리해서 본다

- **노출 확률** 버튼을 누르면 그 영상이 지금 홈 화면에 띄워지고 있는지 보인다.
- 선택을 받았는지는 **조회수가 높은 것**으로 알 수 있다. 단, **채널 가치는 제외하고** 봐야 한다 — 이건 **기여도**로 판단한다.
- 영상을 올려서 구독자가 증가한 것은 **기여도**로 표시된다.

**규칙:** "홈 화면에 노출되어 선택받았다"는 **노출 확률**로, "그 영상이 채널 성장에 얼마나 기여했나"는 **기여도**로 판단한다. (지표·필터 조작 세부는 문서 06 참조.)

## 4. 풀링 콘텐츠 준비 8단계 (+무위의 단계)

> 각 단계는 뷰트랩 리서치와 함께 돈다. 조작 세부는 문서 06에 위임하고, 여기서는 **설계 논리**를 기준으로 정리한다.

### 1단계 · 성장·성과 좋은 영상 찾기

두 종류의 영상을 구분해서 찾는다.

- **성장하고 있는 영상**: 지금도 조회수가 **올라가는 중**인가?
- **성과가 좋은 영상**: 채널 가치를 빼고 **기여도만으로** 판단한다.

**규칙:** 필터 팁 — **조회수 5만 이상 필터**를 넣어 후보를 좁힌다.

여기서 **키워드 확장 → 기능 단위 분석 → 문제**의 흐름으로 주제를 잡는다.

`키워드 확장 → 기능 단위 분석 → 문제`

> **예시) 알티지 부스터 3 (오메가3/알티지)** — 알티지 부스터 3 → 오메가 3 → 심혈관 건강 → 목·어깨 통증. 실제 방법: 네이버에 **오메가 3의 기능**을 쳐서 기능을 확인하고, 그다음 **심혈관 건강이 나쁘면 나오는 문제점**을 인터넷으로 서칭한다.

#### 내 제품 대입 · 논리적 확장(개요)

같은 방식을 내 상품에 대입하는 것이 **논리적 확장**이다. (상세 공식·표는 5장 참조.)

`마케팅 훈련소 → 마케팅 툴 / 마케팅 대행 → 기능(콘텐츠 업로드·기획·분석) → 고객이 겪는 문제들`

> **목표:** "내 제품이 이 세상에 존재해서 감사하다"는 마음이 들도록 만드는 것. 그러려면 이 문제를 **구체적인 사례**로 만들어야 한다 → 이때 쓰는 도구가 **뷰트랩**이다.

#### 마케팅을 못하면 생기는 문제점 (실제 서칭)

1. **고객이 왜 사야 하는지 전달하지 못한다.** — 제품의 가치가 고객의 언어로 번역되지 않으면 구매가 일어나지 않는다.
2. **콘텐츠를 올려도 반응이 없다.** — 콘텐츠를 많이 올리는 게 중요한 게 아니다. 고객이 구매 결정을 내리기까지 필요한 생각을 하나씩 만들어 주는 것이 핵심이다.
3. **돈과 시간을 많이 쓰고도 성과를 판단하지 못한다.** — 성과를 보는 구조가 없어 감으로 하게 된다. 잘된 이유도, 안된 이유도 모른다.
4. **고객의 구매 여정을 설계하지 못한다.** — 좋은 마케팅은 억지로 설득하는 게 아니라, 고객이 자연스럽게 구매 결정을 내리도록 **필요한 정보를 순서대로 제공하는 것**이다.
5. **차별점이 없어 보인다.**
6. **대행사를 써도 관리를 못한다.**
7. **매출이 운에 의존하게 된다.**

> **설득 구조:** 이런 문제들은 대행사를 쓰거나 여러 마케팅 툴을 겹쳐 쓰면 해결할 수는 있다. 그렇지만 내 제품은 이 문제를 **더 가시화해 주고, 더 가성비 있게(비용은 낮추고 효과는 볼 수 있게)** 해준다 — "그렇다~" 하고 고개를 끄덕이게 만드는 설득 구조를 짠다.

#### 타깃 정하기 — 광고 대행 vs 콘텐츠 마케팅

타깃은 **작은 브랜드, 스타트업**이다. 스스로 던지는 질문: "이 효과가 즉시적인가? 콘텐츠 마케팅은 길게 봐야 하는데, 그래서 일반적으로 광고 대행이 많긴 하다. 나는 광고 대행으로 가야 하나, 콘텐츠 마케팅으로 가야 하나?"

> **결론:** **광고에 큰 비용을 쏟기도 힘들고, 실제로 브랜드 파워를 키우고 싶어 하는 사람들**이 내 제품을 구매하겠다.

#### 같은 맥락을 더 좋은 표현으로 바꿔 뷰트랩에서 찾기

같은 맥락이라도 **더 좋은 단어·문장으로 표현**을 다듬고, 그 표현을 뷰트랩에서 찾는다. 알고리즘을 잘 탄 영상은 조회수가 **꿀렁꿀렁** 올라간다.

#### 실제 검색 — 문제 표현을 콘텐츠 제목으로

> **예시) 문제 "콘텐츠를 올려도 반응이 없다"** — 검색해서 나온 실제 콘텐츠: **"1인 창업 유튜브로 사업하는 법, 진짜 누구나 할 수 있는 핵심 원리".** 이걸 아래처럼 바꾸라는 뜻이다.

> **예시) 문제 "마케팅이 어렵다"** — "사업 중인데 모르면 큰일 나는 마케팅의 개념" / "1인 창업 중인데 모르면 큰일 나는 마케팅 개념". 또 다른 표현 후보: **"인스타 마케팅 안 되는 이유".**

여기서 막히는 지점: **"논리적 확장을 하는 방법을 잘 모르겠다."** → 5장에서 완전 정리한다.

### 2단계 · "어떻게 하면 더 잘할 수 있을까?"

같은 맥락을 **더 좋은 단어·문장으로 표현**하는 단계다. **핫 비디오에서 나와 공통되는 구조를 파악하고, 그 문맥 구조를 내 콘텐츠에 적용**한다.

> **예시) 걱정 기반 콘텐츠 (안구건조증)** — 눈이 안 보일 때 → 타깃은 "눈이 안 보일까 걱정하는 사람". 걱정 기반의 핫 비디오를 찾아 공통점을 발견한다.
> · 참고 사례: **"부동산 매매·임대차 계약할 때 특약란에 이 문구 쓰면 망합니다!"** → 걱정 기반 콘텐츠임을 인지. 타깃이 겪을 일반적 상황을 썸네일에서 다룬다.
> · 내 것으로 변환: **"아침에 눈 떴을 때 이 행동 하면 제대로 안구건조증 옵니다."** → 구조를 동일하게 만들어 히트하는 구조를 그대로 배워 온다.

> **예시) 삼성전자 AI 채널 (슬라이드+목소리 핫 비디오)** — "[삼성전자] 종가 35만원 마감!! 내일 난리났습니다!! 삼전 초대박 심장마비 소식 터졌습니다 '이것' 반드시 알고 가셔야 합니다!" — 내가 원하는 형식의 채널이다. 영상 스타일이 **슬라이드와 목소리 기반**으로 전달된다. 완전히 AI로 만든 채널이고, 현재 종목 추천해 주는 사이트로 연결시키고 있다.

> **예시) 현상·욕구를 건드리는 "후회" 콘텐츠 (34살 후회 / 비포애프터)** — "한 살이라도 어릴 때 알았으면 좋았을 30가지… 저는 34살 되어서야 알게 됐네요.." 이걸 보는 사람은 비슷하거나 더 낮은 나이대로, **후회하지 않기 위해** 채널을 본다. **현상·욕구와 관련**된다("나도 저렇게 후회하지 않게 미리 하고 싶다", "이제 와서라도 저거 하고 싶다"). 자기관리 콘텐츠다.
> · 변형: "일 년이라도 먼저 알았으면 좋았을 10가지… 저는 창업하고 나서야 알게 됐네요…"
> · 구조 팁: 원고 첫 화면이 바로 **비포&애프터 사진**이다. 비포는 여드름 많은 사진, 애프터는 피부 좋은 사진. **보상을 먼저 보여주고 그다음 욕구를 들게 만든다.** 내가 피부가 안 좋으면 보게 되어 있다. "15년을 15분 안에 알게 된다."

### 3단계 · 노출 확률이 높은 주제 확인

1. 노출 확률 버튼을 클릭하고, 분석이 완료되면 **normal·good·great만 클릭**하여 설정한 뒤 결과를 확인한다.
2. 검색된 결과를 **노출 확률이 높은 순으로 정렬**한다.
3. 지금 어떤 주제의 영상이 노출 확률이 높은지 확인한다. (노출 확률은 지금 유튜브 알고리즘을 타고 있을 확률이라 계속 달라질 수 있다.)

**규칙:** 성장하고 있는 영상 = 지금도 조회수가 올라가는 중인가? = **최근 24시간 기준 조회수 변화가 일어나는가?** 조회수 변화는 특정 시점에만 일어날 확률이 높다. 노출 확률로 확인하면 → 탐색의 90%에서 증가 → 그 탐색의 90%가 홈 화면에서 일어난다.

> **1단계 vs 3단계:** 1단계는 **트렌드적인 큰 것**을 보는 것, 3단계는 **단기적 관점**에서 보는 것이다. (노출 확률이 높은 게 없다면 성장하고 있는 영상을 본다.)
> · 응용: 노출 확률이 높은 게 예컨대 "EBS 전문 의사의 소견"이라면, 포기할 게 아니라 **"내가 그 전문 의사의 소견을 인터뷰로 따올 수 있나? 아니면 그 영상을 리뷰할 수 있을까?"** 관점으로 생각해 본다. → 이게 3단계 관점으로 풀링 콘텐츠를 기획하는 방법이다.

> **예시) 내 채널 주제 후보** — · AI 시대 월급쟁이가 1인 기업가가 되는 가장 빠른 방법 · 1인 개발자 광고 꼭 해야 할까? | 앱 개발 창업 전 반드시 알아야 하는 마케팅 상식 → **키 콘텐츠 주제** · 절대 망하지 않고 성공하는 창업 방법 (1인 창업, 자기 창업)

### 4단계 · 오래됐는데도 노출 확률이 높은 주제 찾기

**규칙:** 노출 확률이 높은데 **오래된 영상들 — 그게 노다지다.** 오래되었으나 노출 확률이 높다는 것은 **클래식**이라는 뜻. 특별히 신경 써서 만들어야 하고, 4단계는 **한 방을 노릴 수 있다.**

게시일이 오래됐음에도 노출 확률이 좋은 영상은 **나중에 노출 확률이 안 좋아져도 한 번 더 올라갈 수 있는 주제**를 다뤘을 가능성이 크다. 그래서 영상 수집을 통해 저장해 둔다. (이런 클래식 주제가 에버그린의 원천이다 — 3장 참조.)

### 5단계 · 3단계 파생 — 갑자기 떡상 중인 채널 배우기

노출 확률이 좋다. 그런데 그 영상의 채널을 보니, **최근 7일 기준으로 채널에 올라간 전체 영상 중 노출 확률이 좋은 비율이 높다.** 즉 최근 7일 동안 그 채널이 갑자기 떡상해 다른 영상들까지 함께 떡상 중이다.

**규칙:** 그런 채널에서는 그 채널이 다루는 **주제를 확인하고 나도 그 주제를 다룬다.** 그러면 추천으로 붙을 수 있다 — 해당 주제를 보는 사람이 늘어나 홈 화면에 함께 뜰 수 있기 때문이다.

절차(뷰트랩):
1. 채널 찾기 메뉴에 내 유튜브 채널 분야와 관련된 키워드를 검색한다.
2. 채널 개설일 순으로 정렬한 뒤, 관심 있는 채널을 클릭해 채널 정보와 **인기 동영상 Top 10**을 보고 주제를 참고한다.
3. 성장 속도 버튼을 클릭해 분석이 완료되면, 채널 개설일 최신순으로 정렬한 뒤 **성장 속도가 좋은 채널**을 확인한다.
4. 성장 속도가 좋은 채널을 클릭해 상세 정보 팝업을 확인하고, 마음에 들면 팝업 상단 우측의 **채널 분석 추가** 버튼으로 채널 분석 메뉴에 추가한다.

> **광고·협업 활용:** 이런 채널들에 **광고를 주면 효율이 좋다.** 광고를 하거나, 아니면 같이 협업해서 영상을 만들 수도 있다.

> **예시) 채널 탐색 중 떠오른 주제** — "나도 이렇게 60일 동안 총 11가지 방법으로 마케팅 해봤습니다. 마케팅 때문에 저처럼 불안한 사람들을 위한 영상" → **AI로 마케팅의 방식이 바뀌어야 한다.** 이렇게 주제를 만들어도 되겠다.

> **예시) 내 채널 주제** — "직원 10명 업무를 AI가 다 해줘요 — AI로 마케팅 팀 만들고 1인 창업하는 방법" → 마케팅 자동화 + 1인 창업하는 사람들을 끌어당김 → "나도 저렇게 마케팅 자동화 시키고 싶다"는 욕구 만들기 → 계획 → 행동 유도.

### 6단계 · 조합

1. 채널 분석 메뉴로 이동해 추가한 채널의 영상을 **기여도 높은 순**으로 정렬한 뒤, 채널 성장에 극적으로 기여한 **퍼스트 히트 영상**의 주제를 확인한다.
2. 노출 확률 버튼을 클릭해 분석이 완료되면 노출 확률 높은 순으로 정렬하고, 제목·썸네일을 보며 어떤 주제로 제작하면 좋을지 **키워드**를 생각한다.
3. 영상 찾기 메뉴에 그 키워드를 검색한 뒤, 검색이 완료되면 노출 확률 버튼을 클릭해 분석하고 필터에서 **normal·good·great만** 클릭해 결과를 확인한다.
4. 노출 확률 높은 순으로 정렬해 제목·썸네일을 확인하고, 마음에 드는 키워드를 확인한 뒤 **핫 비디오 서비스**로 이동한다.

### 7단계 · 무위(無爲)의 단계

영상을 찾고 노출 확률을 확인한 뒤 **핫 비디오 기능을 연계**한다. 핫 비디오에서 특히 끌리는 제목·썸네일을 보면서, 주요 키워드에 내가 생각한 키워드를 조합하거나 **디벨롭**해 새로운 제목을 만든다.

**규칙:** 앞 단계를 충분히 반복하면, **핫 비디오 영상만 봐도 내가 해야 할 콘텐츠와 바로 접목**이 된다. (기준: 최소 구독자 **20만 이상**.)

### 8단계 · 도저히 뭘 해야 할지 모르겠다면 핫 채널에서 주제 찾기

채널 찾기(유튜브 뭐하지?)에서 **핫 채널**을 검색하면 성장 속도가 높은 채널들이 나열된다. 채널 개설일을 최신순으로 정렬해, 어떤 주제로 운영하는 채널이 성장이 빠른지 확인한다.

**규칙 (순서 원칙):** **1~5단계를 먼저 마스터**해야 한다. 매출 기준으로 **500만 원이 넘어가면 6단계**를 해야 한다.

## 5. 논리적 확장 (완전 정리)

**정의:** 논리적 확장은 단순히 키워드를 넓히는 게 아니라, **내 상품 → 기능 → 고객이 겪는 문제 → 그 문제를 가진 사람 → 그 사람이 보고 싶어 할 콘텐츠 주제**로 확장하는 것이다. (풀링 = 시청자를 잠재 소비자로 바꾸는 콘텐츠, 키 = 잠재 소비자를 실제 소비자로 바꾸는 콘텐츠. 핵심은 "우리 제품의 기특장을 기반으로 어떤 문제를 인식시킬 것인가".)

### 5.1 내 상품에 적용하면

내 상품은 **마케팅 자동화 / AI 기반 마케팅팀 / 콘텐츠 마케팅 운영 시스템** 쪽이다. 타깃 문제는 "마케팅을 잘 모름, 마케팅팀을 꾸릴 여력이 없음, 콘텐츠 마케팅을 모르겠음, 광고 효율이 안 남, 꾸준히 콘텐츠를 올릴 자신이 없음"으로 정리된다.

| 단계 | 내 상품 기준 |
|---|---|
| 상품 | 마케팅 훈련소 / AI 마케팅팀 / 마케팅 자동화 시스템 |
| 기능 | 콘텐츠 기획, 업로드, 분석, 반복 개선, 자동화 |
| 고객 문제 | 마케팅을 어떻게 해야 할지 모름 / 팀을 뽑을 돈이 없음 / 광고비가 새는 느낌 / 콘텐츠를 꾸준히 못 올림 |
| 고객 상황 | 작은 브랜드 대표, 스타트업, 1인 사업자, 크리에이터, 초기 쇼핑몰 |
| 풀링 콘텐츠 주제 | "인스타 열심히 해도 손님이 안 오는 이유", "광고비 쓰는데 문의가 없는 이유", "직원 없이 마케팅팀처럼 일하는 법" |
| 키 콘텐츠 주제 | "마케팅 대행사 쓰기 전에 작은 브랜드 대표가 먼저 알아야 할 것" |
| 상품 연결 | AI 마케팅팀 진단 / 구축 제안 / 마케팅 자동화 솔루션 |

**규칙:** **"AI 마케팅 자동화 툴 좋습니다"** 가 아니라, **"작은 브랜드가 왜 마케팅을 해도 매출이 안 나는가?"** 에서 시작해야 한다.

### 5.2 논리적 확장 vs 키워드 확장

**키워드 확장**(검색량·시장 크기 기준): *마케팅 훈련소 → 마케팅 자동화 → AI 마케팅 → 인스타그램 마케팅 → 업무 자동화 → AI 자동화 → AI.* (내 상품을 "마케팅 자동화 - 유튜브·인스타그램·쓰레드·X"로 두고, 대행사 플로우를 AI로 최적화해 낮은 비용으로 마케팅한다는 방향.)

**논리적 확장**은 이렇게 간다:

`마케팅 훈련소 → AI 마케팅 자동화 → 콘텐츠 기획·업로드·분석을 대신 굴려줌 → 작은 브랜드는 마케팅팀이 없어 이걸 못 함 → 대표가 직접 인스타·광고·콘텐츠 하다가 지침 → "왜 열심히 올려도 손님이 안 오지?" 문제 인식 콘텐츠 필요`

| 구분 | 질문 |
|---|---|
| 키워드 확장 | 사람들이 어떤 단어를 많이 검색하지? |
| 논리적 확장 | 내 상품의 기능이 고객의 어떤 문제로 번역되지? |
| 콘텐츠 확장 | 그 문제를 가진 사람이 클릭할 만한 말은 뭐지? |

### 5.3 핵심 문제는 "자동화"가 아니라 "마케팅 구조 부재"

상품을 **AI 자동화 툴**로만 보면 콘텐츠가 너무 기능 중심으로 간다.

- **BAD:** AI로 콘텐츠 자동 생성하는 법 / 콘텐츠 자동 업로드하는 법 / AI 마케팅 자동화 세팅법 / SNS 자동화 툴 추천 — 조회수는 나와도 **구매 의도는 약하다.**
- **GOOD:** 상품을 "작은 브랜드가 마케팅팀 없이도 마케팅 구조를 굴리게 해주는 시스템"으로 보면 논리적 확장이 쉬워진다.

> **핵심:** "AI를 못 써서 문제가 아니다. 고객을 움직이는 마케팅 구조가 없어서 문제다." 이 방향은 PRD와도 맞는다 — PRD의 중심은 '사람'이고, 핵심은 사람들이 왜 반응하고 무엇에 설득되며 어떤 감정에서 구매까지 가는지를 사람이 이해하는 것. AI·자동화는 그 감각이 쌓이는 속도를 높이는 도구다.

**규칙 (포지셔닝):** **"AI 마케팅 자동화 툴"** 이 아니라 **"작은 브랜드가 마케팅팀 없이도 고객을 움직이는 구조를 반복 실행하게 해주는 시스템".**

### 5.4 바로 쓸 수 있는 논리적 확장 공식

> **공식:** 내 상품은 **[기능]**을 제공한다. 그런데 고객은 그 기능을 원하는 게 아니라 **[문제 해결]**을 원한다. 그 문제는 고객의 일상에서 **[현상]**으로 나타난다. 그래서 풀링 콘텐츠는 **[현상·불만·착각]**을 건드려야 한다. 키 콘텐츠는 **[해결 구조·계획]**을 제시하고, 상품은 그 계획을 실행하는 **[도구·시스템]**으로 등장해야 한다.

> **예시) 공식 대입** — 내 상품은 **콘텐츠 기획·업로드·분석·자동화**를 제공한다. 그런데 고객은 자동화를 원하는 게 아니라 **마케팅팀 없이도 매출로 이어지는 마케팅 구조**를 원한다. 그 문제는 **인스타를 열심히 해도 문의가 없고, 광고비를 써도 전환이 안 나고, 콘텐츠를 꾸준히 못 올리는 현상**으로 나타난다. 그래서 풀링 콘텐츠는 **"열심히 했는데 왜 안 되지?"** 를 건드리고, 키 콘텐츠는 **작은 브랜드가 마케팅팀 없이 고객 이동 경로를 만드는 법**을 제시하며, 상품은 그 구조를 실행하는 **AI 마케팅팀·자동화 시스템**으로 등장한다.

### 5.5 콘텐츠 세트로 바꾸면

**규칙:** **풀링 콘텐츠 4개 + 키 콘텐츠 1개**가 하나의 세트가 되어 **현상 → 욕구 → 계획 → 행동 → 보상**을 완성한다.

1. **풀링 1 · 현상 인식** — 제목: "인스타를 열심히 해도 손님이 안 오는 이유". 고객 머릿속: *"나도 열심히 올리는데 왜 문의가 없지?"* 상품 이야기는 거의 하지 않고 문제 인식만 시킨다.
2. **풀링 2 · 문제 심화** — 제목: "광고비는 쓰는데 문의가 없는 브랜드의 공통점". 고객 머릿속: *"콘텐츠만 문제가 아니라 광고 이후 설득 구조가 없어서 돈이 새는구나."* 문제의 심각성을 느낀다.
3. **풀링 3 · 욕구 형성** — 제목: "직원 없이 마케팅팀처럼 일하는 작은 브랜드의 방식". 고객 머릿속: *"나도 사람을 뽑지 않고 마케팅팀처럼 운영하고 싶다."* 상품의 핵심 욕구가 생긴다.
4. **풀링 4 · 계획 진입** — 제목: "AI로 콘텐츠 100개 만들어도 매출이 안 나는 이유". 고객 머릿속: *"AI 툴이 먼저가 아니라, 고객을 움직이는 마케팅 구조가 먼저구나."* 키 콘텐츠로 넘기는 다리 역할.
5. **키 콘텐츠** — 제목: "마케팅 대행사 쓰기 전에 작은 브랜드 대표가 먼저 알아야 할 것". 역할: *"마케팅은 콘텐츠 생산이 아니라 고객 이동 경로를 설계하는 일이다."* 여기서 상품을 연결한다 → *"이 구조를 혼자 매번 설계·실행하기 어렵기 때문에, AI 마케팅팀·마케팅 훈련소가 필요하다."*

### 5.6 막히는 지점 — 상품에서 바로 콘텐츠로 가려 해서

- **BAD:** 마케팅 훈련소 → 어떤 콘텐츠 만들지? (이렇게 가면 막힌다)
- **GOOD:** 마케팅 훈련소 → 어떤 기능이 있지? → 그 기능은 고객의 어떤 결핍을 해결하지? → 그 결핍은 일상에서 어떤 불만으로 나타나지? → 그 불만을 가진 사람이 클릭할 문장은 뭐지?

| 상품 기능 | 고객 결핍 | 고객의 실제 말 | 콘텐츠 제목 |
|---|---|---|---|
| 콘텐츠 기획 | 뭘 올려야 할지 모름 | "맨날 제품 소개만 하게 돼요" | 제품 자랑만 하는 인스타가 안 팔리는 이유 |
| 자동 업로드 | 꾸준히 못 함 | "해야 하는 건 아는데 시간이 없어요" | 대표가 직접 SNS 하다가 지치는 이유 |
| 성과 분석 | 뭐가 먹히는지 모름 | "조회수는 나오는데 매출이 없어요" | 조회수는 높은데 구매가 안 나는 콘텐츠의 공통점 |
| AI 마케팅팀 | 사람 뽑을 돈 없음 | "마케터를 뽑기엔 부담돼요" | 작은 브랜드가 마케팅팀 없이 성장하는 방식 |
| 고객 흐름 설계 | 광고비가 샘 | "광고를 켜도 문의가 없어요" | 광고비를 써도 문의가 없는 진짜 이유 |

### 5.7 앞으로 기획할 때 기준 — 3가지 체크

순서는 **주제 → 썸네일 → 도입부 → 원고**. "주제 선정은 됐으니 그걸 왜 볼까를 고민한다." 썸네일로 들어온 유저를 도입시키고, 욕구를 충족시키고, 계획을 제공하면서 상품을 이야기한다. (썸네일·원고 세부는 문서 07 참조.)

- **체크 1. 어떤 문제를 인식시키나?** — 나쁜 예: "AI 마케팅 자동화 하는 법" / 좋은 예: "AI로 콘텐츠 100개 만들어도 매출이 안 나는 이유"
- **체크 2. 내 키 콘텐츠를 볼 이유가 생기나?** — "아, 콘텐츠를 많이 만드는 게 문제가 아니구나." → "그럼 고객이 구매까지 가는 구조가 뭔데?" → 키 콘텐츠 클릭
- **체크 3. 상품을 살 이유가 생기나?** — "구조를 알아야 하는 건 알겠는데 이걸 내가 매번 하긴 어렵네." → "그럼 이 구조를 대신 굴려주는 시스템이 필요하네." → 마케팅 훈련소·AI 마케팅팀 연결

> **한 줄 정의:** "AI 마케팅 자동화"라는 기능을 파는 게 아니라, 작은 브랜드 대표가 겪는 '마케팅팀 부재·광고비 낭비·콘텐츠 구조 없음'이라는 문제로 번역해, 그 문제를 인식시키는 콘텐츠 주제로 확장하는 것.
> **제일 먼저 잡을 메인 논리:** 작은 브랜드는 콘텐츠를 못 만들어서 안 팔리는 게 아니라, 고객이 구매까지 이동하는 구조가 없어서 안 팔린다. 마케팅 훈련소는 그 구조를 AI와 자동화로 반복 실행하게 해주는 시스템이다.

## 6. 풀링 콘텐츠 기획 — 정리와 실전

이번 기획의 목표는 세 가지다: ① 풀링 콘텐츠란 무엇인가 ② 풀링 콘텐츠 기획 방법 ③ 풀링 콘텐츠 주제 선정.

### 6.1 풀링 콘텐츠란 무엇인가 (재정리)

`풀링 → 키 → 랜딩`

기본 수익화 구조에서 **키 = 잠재 고객 구매 전환**, **풀링 = 키 콘텐츠를 보게 만들기 = 잠재 고객 모으기.**

### 6.2 풀링 콘텐츠의 핵심 2요소

1. 사람들이 겪고 있는 문제
2. 문제에 대한 해결 방법

**규칙:** 이 둘을 설득하는 것이 풀링 콘텐츠다. 그리고 **문제에 대한 해결 방법 중 하나가 키 콘텐츠이거나, 결론이거나, 키 콘텐츠를 보게 만드는 것**이어야 한다.

- **키:** 이걸 보면 **살 것 같아?**
- **풀링:** 이걸 보면 **키 콘텐츠를 볼 것 같아?**

> **예시) 도시락 / 밀폐용기** — **풀링:** "일주일이 편한 초간단! 샐러드 도시락 만들기" — 5분 만에 쓰는 방법이 있는데 밀폐 용기를 잘 봐야 한다며 다리를 놓는다. **키:** "냉동용기? 소분용기? 유리? 반찬통 사기 전에 꼭 보세요 — 내돈내산 냉장고 정리 용기 장단점 비교" → 밀폐 용기의 장단점을 이야기하며 설득한다.

### 6.3 풀링 콘텐츠를 어떻게 기획하는가

`현상 → 욕구 → 계획 → 행동 → 보상`

> **예시) 외투 구매 흐름** — 갑자기 춥다(현상) → 외투가 있었으면 좋겠다(욕구) → 주말에 마트 가야지, 무신사에 접속해야지(계획) → 구매한다(행동) → 따뜻한 출근길(보상)

> **예시) 마케팅 훈련소 흐름** — 매출이 떨어진다 / 마케팅 팀이 없어 마케팅이 어렵다 / 경험이 없어 어렵다 / 사업을 이제 시작해 아이템은 있는데 모르는 게 많다(현상) → 마케팅으로 매출을 올리고 싶다(욕구) → 마케팅 툴 사야지, 대행사 써야지, 광고 해봐야지(계획) → **마케팅 훈련소를 구매한다(행동)** → 매출이 오른다(보상)

**규칙 (기획 순서):** **키 콘텐츠가 어디서부터 어떻게 설득할지를 먼저 정한다.** 그래야 풀링이 어디서부터 어디까지 설득할지가 나온다.

> **내 경우:** 키 콘텐츠는 주로 **욕구 → 계획 → 행동**이 많다. 그게 아니면 계획 → 행동. 마케팅에 대한 니즈는 다 있고("마케팅 잘하고 싶다"는 욕구는 당연히 있으니까), 그러니까 **현상이 풀링 콘텐츠가 되어야 한다.**

### 6.4 키 콘텐츠와 같은 단계에서 시작할 수도 있다

풀링이 키와 같은 단계(예: 둘 다 계획, 둘 다 욕구)에서 시작할 수도 있다. 다만 아직 명확하게 감이 쌓이지는 않는다.

> **예시) 살림(정리정돈) 채널** — **풀링:** "옷 도저히 못 버릴 때, 따라 하면 무조건 버릴 수 있는 6가지 방법 | 미니멀 라이프 옷 버리기" → 정리정돈 정보 전달. 여기서 더 잘하고 싶다면 키 콘텐츠로. **키:** "정리 고수도 감탄하는 정리 쉽게 하는 5가지 방법" → 정리정돈 정보 전달 + 제품. → **둘 다 '계획'에 해당.**

> **내 것으로 써먹으면:** **풀링** = 마케팅을 잘하는 정보를 전달하는 콘텐츠(더 잘하고 싶다면 키 콘텐츠로) / **키** = 마케팅을 잘하는 정보 전달 + 제품 → 구매 전환.

> **예시) 패션 채널** — **풀링:** "여름 코디 실패 없는 5가지 — 덥다고 막 입으면 실루엣 망합니다" → 여름 코디 방법. **키:** "원피스 왜 나만 이상할까? 이 포인트 하나만 기억하세요 — 7가지 유형 체형별 원피스 성공 공식" → 원피스 코디 방법. → **둘 다 '욕구'에 해당**하지만, 키 콘텐츠는 구매 전환까지 이끌었다.

### 6.5 키 콘텐츠·풀링 콘텐츠 분리 (같은 결, 다른 단계)

> **예시) 여행 채널** — **풀링:** "공항 경유 해외여행 짐, 캐리어 분실 예방 | 비행기 환승 짐" → 여행 가고 싶은 사람의 **현상**. 이런 정보를 아는 것도 좋지만 여행 갈 때 필수품을 활용하는 것도 좋다며 다리를 놓는다. **키:** "베트남 여행 준비물 짐 싸기 — 꼭 필요한 필수품 & 가져가면 유용한 아이템" → **계획부터 행동**을 이끈다.

> **예시) 요리(압력솥) 채널** — **풀링:** "요리사들도 잘 모르는 갈비찜 제대로 만드는 방법 — 200% 맛 상승" → 요리 방법 중간에 저압 냄비가 좋다는 장점을 빠르게 설명하고, 궁금하면 키 콘텐츠로 보라고 유도. 이 장점을 설명할 때는 **소비자에게 문제를 인식시켜야** 욕구가 생긴다. **키:** "유튜브에서 난리 난 역대급 냄비! 재고 있을 때 무조건 들이세요" → 제품 홍보·어필을 많이 한다. 압력솥이 필요하면 살 것이다.

### 6.6 주제 선정

**규칙:** 키 콘텐츠의 썸네일·주제를 선정했다면, **풀링을 어디서부터 어디까지 할 건지**를 정한다.

## 7. 실제 풀링 콘텐츠 기획 (내 채널 적용)

`현상 → 욕구 → 계획 → 행동 → 보상`

**규칙:** **욕구 → 계획 → 행동**은 키 콘텐츠로 들어가 있다. 그러니 내 풀링은 **현상 → 욕구** 구간을 담당한다.

### 7.1 현상 — 6가지 진입점

1. 아이템은 좋은데 매출이 떨어진다. → "제대로 마케팅 해보자"
2. 마케팅 팀이 없는데 기업에서 하는 마케팅을 해보고 싶다. → "마케팅 본질이 중요한데, 키 콘텐츠 보자"
3. 마케팅 경험이 없어서 어렵다 — 마케팅 공부법!!! → "그럼 마케팅 본질부터 생각해봐"
4. 팀원이 적어서 꾸준히 콘텐츠 올리기가 어렵다. → "자동화는 좋은데, 마케팅 본질이 더 중요해. 키 콘텐츠 보자"
5. 사업을 이제 시작해서 아이템은 있는데 마케팅을 모르겠다. → "넌 좋아. 광고비 아낄 방법이 있어. 마케팅의 본질을 이해해야 해"
6. 광고비는 쓰기 싫다면 — "광고비 0원으로 매출 극대화" → "광고비는 안 써도 되는 마케팅인데, 본질이 중요해. 키 콘텐츠 보자"

**규칙:** 이 6개의 현상은 모두 **'마케팅의 본질' 키 콘텐츠**로 이어지게 만든다. 풀링을 전부 **"1인 창업자의 마케팅 공부법"**으로 가도 되겠다. 내 채널에서는 **적은 리소스로 마케팅하는 방법**을 다룬다.

그래서 **"1인 창업자의 마케팅 공부법"**을 채널 핵심 주제로 잡는다. 1인 창업자, 작은 규모의 브랜드, AI 사업가가 마케팅을 공부하기 위해 내 채널을 찾는다. 이들의 현상은 **마케팅을 잘 모르고, 리소스를 많이 쏟기 어렵고, 마케팅 팀원이 없다.** 그러나 **마케팅을 제대로 해보고 싶은 욕구**가 있다. 이들에게 마케팅 공부법을 알려주며 풀링을 한다. 이건 **현상 → 욕구 단계의 풀링 콘텐츠**다.

> **연결:** "마케팅 잘하는 방법"은 마케팅 대행사, 직접 하기, 마케팅 툴 조합 — 모두 복잡한 단계다. **하지만 내 제품을 사용하면 영상에서 다룬 모든 주제가 다 접목된다.** 이건 **욕구 → 계획 → 행동의 키 콘텐츠**다.

> **예시) 전체 흐름 재확인** — 매출이 떨어진다 / 마케팅 팀이 없어 어렵다 / 경험이 없어 어렵다 / 사업 초기라 모르는 게 많다(현상) → 마케팅으로 매출을 올리고 싶다(욕구) → 마케팅 툴·대행사·광고(계획) → 마케팅 훈련소를 구매(행동) → 매출이 오른다(보상)

### 7.2 현상 → 욕구 · 풀링 제목 후보

진입 현상: **"1인 창업하면서 마케팅 어디서부터 시작해야 하는지 막막하다."**

- **풀링:** 1인 창업의 핵심은 사실 **레버리지**다. 그 레버리지의 기본은 본질을 내가 얼마나 잘 알고 있느냐다.
- **풀링:** 1인 창업자가 할 수 있는 최소한의 마케팅 방법
- **풀링:** 작은 브랜드가 할 수 있는 최대한의 마케팅 방법
- **풀링:** 마케팅의 본질을 레버리지하는 방법

### 7.3 욕구 → 계획 → 행동 · 키 콘텐츠 방향

**규칙:** 마케팅 레버리지는 **'계획' 단계**인데, 이것만 다루기에는 콘텐츠 조회수 유입이 적을 것 같다. 그러니 **'욕구'부터 시작**하자 — "나도 저 마케팅 방법대로 해보고 싶다."

구조: **마케팅의 본질 3가지 → 이 본질을 레버리지 → 내 상품.**

- **GOOD:** 작은 브랜드는 **광고비보다 먼저 고객이 믿을 이유**를 만들어야 한다.
- **주의:** 작은 브랜드는 **대기업처럼 마케팅하면 안 된다.**

**타깃 규모 기준:** **1인 창업 ~ 작은 브랜드(5~6명 정도 있을 때).**

## 8. QnA

> **Q. 제약 영업이 노출 확률 낮은 영상만 나온다** — **제약 영업 "취업"**이 핵심이다. 취업 → 돈, 자아실현 → 직장 고민. "내가 백수일 때 돈을 많이 벌고 싶었는데 그 방법이 제약 영업이었다. 그러니까 나한테 와서 영업 취직을 소개받아라"로 연결.

> **Q. 마사지기 결이 맞는 콘텐츠를 못 찾겠다** — 마사지기 → 다리 풀어주기 → 근성장에 도움. / 마사지기 → 효도 → 노년 근육 풀어주는 효과. (하나의 기능을 여러 문제로 확장.)

> **QnA · 키워드 확장 방향 잡기 (족발)** — · 족발 유통 → 족발 창업 → 창업 → 장사 → 장사 시작. 여기서 '족발'을 키워드로 치는 건 **족발을 먹고 싶은 타깃**을 찾는 행동이므로 방향이 다르다. · super vpn > vpn → vpn 기능 → "어떤 문제를 가진 사람이 필요로 하는가?"로 확장.

> **핵심:** **기획이 되어야 아이템에 대한 확신이 선다.** 그다음이 콘텐츠 제작이다.

## 컨설팅 적용 포인트 (AI 사용 지침)

### 상담 시 먼저 물어야 할 질문
- "당신의 상품/서비스의 **기특장(기능·특징·장점)**은 무엇인가요?" → 논리적 확장의 출발점.
- "그 기능이 해결하는 **고객의 문제**는 무엇이고, 그 문제는 고객의 **일상에서 어떤 현상(불만·착각)**으로 나타나나요?"
- "**키 콘텐츠는 소비자 행동 퍼널(현상→욕구→계획→행동→보상)의 어느 구간**을 담당하나요?" → 그래야 풀링이 담당할 구간이 정해진다.
- "목표 매출은 얼마인가요?" → 매출 **500만 원 초과 시 6단계(조합)** 진입 판단.

### 조건 → 조언 (heuristic)
- **조건: 콘텐츠 아이디어가 안 나온다 →** 상품에서 바로 콘텐츠로 점프하지 말 것. **상품 → 기능 → 고객 결핍 → 일상 불만 → 클릭할 문장** 순서로 내려가게 유도(5.6 표 활용).
- **조건: "AI 자동화 좋습니다"류 기능 중심 제목만 나온다 →** 구매 의도가 약하다. "왜 열심히 해도 안 되지?"류 **문제 인식 제목**으로 재작성.
- **조건: 고객 풀이 작아 보인다 →** 키 콘텐츠 논리에만 갇혀 있는 것. **논리적 확장**으로 문제·카테고리를 일반화해 잠재고객 범위를 넓혀라.
- **조건: 채널을 오래 끌고 가고 싶다 →** 에버그린·데일리로 바닥을 깔고, 오래됐는데 노출 확률 높은 '클래식' 주제(4단계)를 수집·저장하게 하라.
- **조건: 키와 풀링이 같은 단계에서 시작 →** 가능하지만(살림·패션 예시) 감이 덜 쌓인 방식이므로, 초보에게는 **현상→욕구 풀링 / 욕구→행동 키**의 명확한 분리를 우선 권장.
- **조건: 노출 확률 높은 게 전문가·기관 콘텐츠(예: EBS 의사) →** 포기 말고 "인터뷰로 따올 수 있나 / 리뷰할 수 있나" 관점으로 재기획.

### 흔한 실수와 교정
- 풀링을 "이걸 보면 살 것 같아?" 기준으로 만드는 실수 → 풀링의 기준은 **"이걸 보면 키 콘텐츠를 볼 것 같아?"**.
- 썸네일을 벤치마킹 대상과 **똑같이** 만드는 실수 → **더 잘해야** 한다.
- 키워드 확장(검색량)과 논리적 확장(문제 번역)을 혼동 → 둘은 목적이 다르다. 잠재고객 범위 확대는 **논리적 확장**의 몫.
- 순서 무시 → **1~5단계 마스터가 먼저**, 6단계는 매출 500만 원 이후.

### 위임 사항
- **뷰트랩 지표·필터·정렬 조작 세부(노출 확률/기여도/성장 속도 버튼, normal·good·great 필터, 조회수 5만 필터, 채널 분석 추가 등)는 문서 06(뷰트랩 리서치)에 위임**한다. 이 문서는 설계 논리에 필요한 범위에서만 언급했다.
- **썸네일·도입부·원고 제작 세부는 문서 07에 위임**한다.
