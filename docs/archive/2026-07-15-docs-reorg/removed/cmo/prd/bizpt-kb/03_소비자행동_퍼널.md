# 소비자 행동 퍼널 (현상 → 욕구 → 계획 → 행동 → 보상)

> **목적**: 구매자가 실제로 움직이는 소비자 행동 5단계 퍼널(현상→욕구→계획→행동→보상)을 정의하고, 이를 판매자의 기획 흐름과 연결해 콘텐츠를 퍼널 단계로 판단·배열하는 기준을 제공한다.
> **원천**: 비즈니스 PT 강의 3주차.
> **관련 문서**: 00_INDEX_사용안내.md, 02_아이템_상품_선정.md, 04_키콘텐츠_기획.md.

## 핵심 요약 (TL;DR)
- **판매자 흐름(기획 순서)**과 **구매자 흐름(소비자 행동 퍼널)**은 방향이 반대다. 판매자는 상품에서 출발하고, 구매자는 자신의 문제(현상)에서 출발한다. 콘텐츠는 "내 상품이 좋다"가 아니라 "고객이 어떤 문제를 겪는가"에서 시작해야 한다.
- **소비자 행동 퍼널(구매자 흐름) = 현상 → 욕구 → 계획 → 행동 → 보상**. 5단계 순서로 고정한다.
- **현상에 공감하는 사람이 많을수록 잠재고객이 늘어난다.** 현상 공감 → 솔루션 공감 → 구매. 그래서 처음부터 상품 장점을 나열하면 안 된다.
- **장점은 보통 '계획' 단계에서 설명된다.** 방법·비교·노하우·장점이 계획 단계에 들어간다.
- **행동 = 구매**. 실제로 도움을 받아 **보상**을 얻어야 퍼널이 완성된다.
- **풀링 콘텐츠는 5단계 중 하나만 담아도 된다.** 단, 결국 **키 콘텐츠의 주제로 연결**되어야 한다.
- **키 콘텐츠가 행동 단계라면, 풀링 콘텐츠는 현상·욕구·계획에 해당한다.**
- 모든 콘텐츠를 분석할 때 "이 콘텐츠는 현상·욕구·계획·행동·보상 중 어디인가"를 판단하는 **감**이 중요하다. 콘텐츠는 낱개가 아니라 고객을 이동시키는 **통로**처럼 배열한다.
- **인스타그램에는 보상 기반 콘텐츠가 많다.** 후기는 보상을 보여줘 → 보상 확인 → 욕구 유발의 역할을 한다.

## 판매자 흐름 vs 구매자 흐름

비즈니스 콘텐츠는 아무 주제나 먼저 만드는 것이 아니라, **팔 상품을 정한 뒤 그 상품을 사게 될 고객이 볼 콘텐츠를 설계하는 방식**으로 만들어야 한다. 3주차의 핵심은 **판매자의 흐름**과 **구매자의 흐름**을 연결하는 것이다.

**정의: 판매자 흐름(기획 순서)** — 목표를 정해놓고 역으로 풀어내는 방식이 가장 빠르게 가는 길이다.

무엇을 팔지 정하기 → 키 콘텐츠 기획 → 풀링 콘텐츠 기획 → 썸네일·제목(풀링)·주제 정하기 → 내용 만들기

**정의: 구매자 흐름(소비자 행동 퍼널)** — 구매자는 상품이 아니라 자신의 문제에서 출발한다. 전혀 다른 순서로 움직인다.

현상 → 욕구 → 계획 → 행동 → 보상

**규칙(두 흐름의 연결):**
1. **판매자는 상품에서 출발하지만, 고객은 문제에서 출발한다.** 그래서 콘텐츠를 만들 때는 "내 상품이 좋다"가 아니라 **고객이 어떤 문제를 겪고 있는지**부터 잡아야 한다.
2. 판매가 일어나는 과정(판매자 관점): 무엇을 팔지 정하기 → 키 콘텐츠 기획 → 풀링 콘텐츠 기획 → 썸네일 제목(풀링)·주제 정하기 → 내용.
3. 구매가 일어나는 과정(구매자 관점): 현상 → 욕구 → 계획 → 행동 → 보상.
4. 이 두 흐름을 연결하는 것이 이번 강의의 핵심이다.

## 소비자 행동 퍼널 5단계 — 정의·의미·역할

고객은 처음부터 구매하지 않는다. 먼저 어떤 현상을 마주치고, 그 현상에 공감하면 욕구가 생기고, 욕구가 생기면 해결 계획을 세우고, 계획을 세운 뒤 행동하고, 행동의 결과로 보상을 얻는다.

현상(문제 인식) → 욕구 → 계획 → 행동 → 보상

| 단계 | 의미(정의) | 콘텐츠에서의 역할 |
|---|---|---|
| **현상** | 고객이 문제를 마주치는 상황(문제 인식) | "나도 저런 문제 있는데"라고 느끼게 함 |
| **욕구** | 문제를 해결하고 싶어지는 마음 | "나도 저렇게 되고 싶다"는 마음을 만듦 |
| **계획** | 해결 방법을 찾아보는 단계 | 방법, 비교, 노하우, **장점 설명**이 들어감 |
| **행동** | 실제 구매 또는 실행 | 상품 구매, 서비스 신청, 문의 |
| **보상** | 행동 이후 얻게 되는 결과 | 후기, 변화, 결과, 성취 |

## 원리: 현상 공감자가 많을수록 잠재고객이 늘어난다

**규칙:**
1. **현상에 공감하는 사람이 많을수록 잠재고객은 늘어난다.**
2. 현상에 공감해야 솔루션에도 공감할 수 있고, 솔루션에 공감할 때 구매가 발생한다. (현상 공감 → 솔루션 공감 → 구매)
3. 그래서 콘텐츠는 처음부터 상품의 장점을 나열하면 안 된다. **장점은 보통 계획 단계에서 설명된다.**
4. 먼저 고객이 문제를 느끼게 하고(현상), 그다음 해결 방법을 찾게 하고(계획), 그 과정에서 내 상품이 필요하다는 흐름을 만들어야 한다.
5. **행동은 구매이며, 실제로 도움을 받아 보상을 얻어야 완성된다.**

## 콘텐츠를 퍼널 단계로 판단하는 법

콘텐츠를 분석할 때는 "재밌다", "조회수가 높다" 정도로 보면 안 된다. 이 콘텐츠가 구매 흐름의 어느 단계에 있는지 봐야 한다. 영상을 보고 이게 현상 기반인지, 욕구 기반인지, 계획 기반인지, 행동 기반인지, 보상 기반인지 알아내는 **감**이 중요하다.

**규칙(판단 질문):** 어떤 콘텐츠든 다음을 물어 단계를 판정한다.
- 이 콘텐츠는 현상 기반인가?
- 욕구 기반인가?
- 계획 기반인가?
- 행동 기반인가?
- 보상 기반인가?

> **예시)** 뷰트랩에 나오는 콘텐츠를 퍼널 기반으로 판단해보는 연습을 한다. 같은 콘텐츠라도 어떤 단계에 있는지 알아야 내 상품에 맞게 응용할 수 있다.

### 어느 단계로 접근할지 — 계획이 충분하면 계획, 부족하면 현상

콘텐츠를 만들 때는 고객이 지금 어느 단계에 많이 모여 있는지 봐야 한다.
- 이미 해결 방법을 찾고 있는 사람이 충분하다면 **계획 단계 콘텐츠**를 만들어도 된다. 예를 들어 고객이 이미 "상세페이지 잘 만드는 법", "랜딩페이지 잘 만드는 법", "이케아에서 뭘 사야 할지" 같은 것을 찾고 있다면 계획 단계로 접근할 수 있다.
- 그런 사람이 충분하지 않다면 더 앞단인 **현상(문제 인식)**으로 가야 한다. 고객이 아직 문제를 명확히 인식하지 못했다면 먼저 이런 콘텐츠가 필요하다.
  - 왜 매출이 안 나오는지
  - 왜 사람들이 구매하지 않는지
  - 왜 지금 방식으로는 해결이 어려운지
  - 어떤 상황에서 이 문제가 발생하는지

> **예시)** 고객이 아직 계획 단계에 없다면, 계획을 말하기 전에 **현상에 공감하게 만들어야 한다.** 통로 안에서 콘텐츠를 어떻게 배열할 것인가를 기획해야 한다.

## 콘텐츠는 통로처럼 배열한다

콘텐츠는 하나하나 따로 존재하는 것이 아니라, 고객을 이동시키는 **통로**처럼 설계해야 한다. 고객이 처음에는 현상을 보고, 욕구가 생기고, 계획을 찾고, 그 계획 중 하나로 내 상품을 만나 구매하고, 보상을 얻는다.

현상 콘텐츠 → 욕구 콘텐츠 → 계획 콘텐츠 → 행동 콘텐츠 → 보상 콘텐츠

**규칙:**
1. 단일 콘텐츠만 보면 안 된다. 이 통로 안에서 고객을 **어디서 데려오고 어디로 이동시킬 것인지** 기획하는 것이 중요하다.
2. 콘텐츠(특히 풀링 콘텐츠)를 만들 때는 "이 콘텐츠는 고객을 어느 단계에서 잡는가? 그리고 다음 단계로 어떻게 이동시키는가?"를 물어야 한다.

## 퍼널과 키·풀링 콘텐츠의 연결

키 콘텐츠 자체의 기획 방법론(핵심 3요소, 뷰트랩 검색 5요소, 설득 순서, 일반화, 전체 프로세스 등)은 **파일 04(키 콘텐츠 기획)**에서 다룬다. 여기서는 퍼널과의 연결만 정리한다.

**규칙(퍼널 ↔ 콘텐츠 유형 대응):**
1. **키 콘텐츠 = 행동 단계.** 문제를 공감한 사람에게 솔루션(=내 상품)을 제시해 구매(행동)로 연결하는 중심 콘텐츠다.
2. **풀링 콘텐츠 = 현상·욕구·계획(및 보상) 단계.** 사람을 끌어오는 입구 콘텐츠로, 구매 흐름 전체를 다 담을 필요가 없다. **현상 / 욕구 / 계획 / 행동 / 보상 중 하나만 담고 있어도 된다.**
   - 어떤 풀링 콘텐츠는 **문제(현상)**를 보여주는 데 집중한다.
   - 어떤 콘텐츠는 **욕구**를 자극한다.
   - 어떤 콘텐츠는 구체적인 **계획·방법**을 알려준다.
   - 어떤 콘텐츠는 구매 **행동**을 유도한다.
   - 어떤 콘텐츠는 후기를 보여주며 **보상**을 증명한다.
3. **내 키 콘텐츠가 행동 단계라면 풀링 콘텐츠는 현상·욕구·계획에 해당된다.** 단, 풀링 콘텐츠는 결국 **키 콘텐츠의 주제로 연결되어야 한다.**
4. 판매자 흐름의 기획 순서(상품 → 키 → 풀링)와 구매자 퍼널(현상 → 욕구 → 계획 → 행동 → 보상)을 겹쳐 보면: 상품 → 고객 문제 → 현상 → 키 콘텐츠 → 풀링 콘텐츠 순서로 역으로 풀어내는 것이 가장 빠르다.

## 인스타그램과 후기 — 보상 기반 콘텐츠

**규칙:**
1. **인스타그램에는 보상을 보여주는 콘텐츠가 많다.** 예쁜 공간, 멋진 라이프스타일, 변화된 모습, 결과물, 후기, 전후 비교 같은 콘텐츠가 여기에 해당한다. 사람들은 보상을 보면 같은 욕구를 갖게 된다.
2. 보상 콘텐츠는 단순히 결과만 보여주는 것이 아니라, 그 보상으로 가는 여러 계획 중에서 **내 상품과 맞는 계획**을 보여줘야 한다.

> **예시)** 보상 콘텐츠가 만들어야 하는 고객의 생각 흐름: 나도 저렇게 되고 싶다. → 그러려면 이 방법이 필요하구나. → 그 방법이 이 상품이구나.

**후기 콘텐츠의 원리:** 후기가 강력한 이유는 **보상**을 보여주기 때문이다. 고객은 후기를 보며 "저 사람이 실제로 결과를 얻었구나"라고 느껴 **보상이 확인**되고, 보상이 확인되면 **욕구**가 생긴다. 후기는 단순한 자랑이 아니라, 고객을 **욕구 단계로 이동**시키는 역할을 한다.

> **예시)** 후기 콘텐츠 흐름: 저 사람도 해결했다 → 나도 해결하고 싶다 → 사고 싶다.

## 예시로 이해하는 퍼널 단계

> **예시) 이케아 콘텐츠 (계획 → 행동)** — **"이케아 가서 살 것"**. 이미 이케아에 갈 계획이 있는 사람을 대상으로 한다. 고객은 이미 계획 단계에 있고, 거기서 무엇을 사야 할지(=어떻게 행동해야 하는지) 알고 싶어 한다. 그래서 이 콘텐츠는 행동 단계에 가깝다. 흐름: 이케아에 갈 계획이 있는 사람 → 어떤 제품을 사야 하는지 알려줌 → 구매 행동으로 이동.

> **예시) 예쁜 주방 콘텐츠 (욕구 → 계획 → 행동 → 보상)** — **"작고 따스한 나의 주방 투어, 살림템"**. 처음부터 제품을 팔지 않는다. 먼저 예쁜 주방을 보여주면 사람들이 "나도 저런 주방을 갖고 싶다"는 **욕구**를 느낀다. 그다음 필요한 살림템을 보며 욕구가 계획으로 넘어가고, 구매하면 행동이 되고, 나도 예쁜 주방을 만들 수 있다는 보상을 상상하게 된다. 흐름: 예쁜 주방을 보여줌 → 갖고 싶다는 욕구 → 필요한 살림템 확인 → 구매 행동 → 예쁜 주방이라는 보상.

> **예시) 볼펜 제작 과정 콘텐츠 (단독으로는 수익화 어려움 / 기능 연결 시 가능)** — 볼펜이 만들어지는 과정을 보여줘도 퍼널 어디에도 넣기 애매하기 때문에 그 자체로는 수익화가 안 된다. 다만 예외가 있다. 공정 과정이 **기능적으로 영향**이 있을 때다. 제작 방식 때문에 더 오래 쓰거나, 더 부드럽게 써지거나, 손목이 덜 아프다는 식으로 고객의 문제 해결과 연결되면 판매가 된다. 핵심은 과정을 보여주는 것 자체가 아니라, 그 과정이 **고객의 문제 해결·구매 이유와 연결되어야 한다**는 것.

> **예시) 후기 콘텐츠 (보상 → 욕구)** — 후기가 강력한 이유는 **보상**을 보여주기 때문이다. 고객은 후기를 보며 "저 사람이 실제로 결과를 얻었구나"라고 느껴 보상이 확인되고, 보상이 확인되면 욕구가 생긴다. 흐름: 저 사람도 해결했다 → 나도 해결하고 싶다 → 사고 싶다. 후기는 단순한 자랑이 아니라, 고객을 욕구 단계로 이동시키는 역할을 한다.

## 컨설팅 적용 포인트 (AI 사용 지침)

**사용자에게 물어봐야 할 질문**
- 팔려는 상품이 무엇이며, 그 상품이 해결하는 **고객의 문제(현상)**는 무엇인가?
- 그 문제(현상)에 공감할 사람이 시장에 충분히 많은가?
- 고객이 지금 어느 단계에 많이 모여 있는가 — 이미 해결 방법을 찾는 **계획 단계**인가, 아직 문제를 모르는 **현상 단계**인가?
- 지금 만들려는(또는 분석 중인) 콘텐츠는 현상·욕구·계획·행동·보상 중 어디인가? 다음 단계로 어떻게 이동시키는가?

**상황별 판단 heuristic (조건 → 조언)**
- 이미 "~하는 법", "~에서 뭘 사야 할지"를 찾는 사람이 충분함 → **계획 단계 콘텐츠**로 접근.
- 그런 사람이 부족함 → 더 앞단 **현상(문제 인식)** 콘텐츠로 먼저 공감시켜라.
- 상품이 보상 이미지(예쁜 공간·변화·결과)로 어필됨(인스타 등) → **보상 콘텐츠**로 욕구를 유발하되, 보상으로 가는 계획 중 **내 상품과 맞는 계획**을 반드시 보여줄 것.
- 후기가 있음 → 후기를 **보상 확인 → 욕구 유발** 장치로 활용(단순 자랑 금지).
- 제작·공정 과정 콘텐츠를 만들려 함 → 그 과정이 **기능적으로 고객 문제 해결과 연결**되지 않으면 수익화가 어렵다고 경고.
- 키 콘텐츠가 행동 단계임 → 풀링 콘텐츠는 현상·욕구·계획으로 배치하되 **결국 키 콘텐츠 주제로 연결**되게 하라.

**흔한 실수와 교정 방향**
- 처음부터 상품 장점을 나열함 → 장점은 **계획 단계**에서. 먼저 현상에 공감시켜라.
- "내 상품이 좋다"에서 출발함 → **고객이 겪는 문제**에서 출발하라(판매자 흐름이 아니라 구매자 흐름 기준으로 콘텐츠 설계).
- 콘텐츠를 "재밌다/조회수 높다"로만 판단함 → **퍼널 어느 단계인지**로 판단하라.
- 단일 콘텐츠만 봄 → 콘텐츠를 **통로**로 배열해 고객을 어디서 잡아 어디로 옮길지 설계하라.
