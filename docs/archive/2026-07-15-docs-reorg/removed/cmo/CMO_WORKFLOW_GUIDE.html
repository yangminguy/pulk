🔍 발굴 자동화 3단계 (키·풀링에서 사용)

"타깃이 실제로 보고 실제로 터진 주제"를 찾는 방식. 무료(YouTube)에서 최대한 거르고, 차감되는 Viewtrap은 추린 소수만.

1
YouTube API 키워드 스크리닝 무료·한도 없음

여러 키워드 검색 → 영상 많고 조회수 높은 키워드 선별. 예: "AI로 돈벌기" 14/20이 5만+, 중앙값 19.9만 → 유망.

2
YouTube 브라우저 + Viewtrap 플러그인 무료

유망 키워드를 YouTube에서 검색 → 플러그인이 주입한 성과도·기여도를 자동 추출 → 5만+·Good+ 필터. 대부분 여기서 거름.

3
Viewtrap 사이트 + 노출확률 이용횟수 차감

추린 소수만 Viewtrap에 검색(확인 모달 자동 처리, ~20초) → 노출확률까지 확인 → normal·good·great만 최종 후보. 기본은 꺼져 있고 명시적으로 켤 때만 차감.

이 3단계는 서버 버튼 하나로 자동 실행됩니다. 발굴 화면에서 키워드 입력 → 실행하면 1단계(YouTube API) + 2단계(플러그인 deepWalk)가 자동으로 돌고 AI 분류까지 끝납니다. 3단계(Viewtrap 노출확률)는 "노출확률까지 확인" 옵션을 켤 때만 추가로 돌아 이용횟수를 1회 차감합니다(기본 꺼짐). 크롬 세션이 죽어 있어도 에러 없이 가능한 단계까지만 진행하고 사유를 알려줍니다.

✅ 승인 게이트 — 사장님이 누르는 곳 (전부 6개)

승인단계무엇을 확인안 누르면
승인 1키 콘텐츠핵심 주제 + Viewtrap 근거풀링으로 안 넘어감
승인 2풀링 세트주변 주제 5개제작 큐로 안 감
승인 3훅(인트로 30초)도입부 초안원고로 안 넘어감
승인 4원고전체 대본음성·렌더로 안 감
승인 5영상 QA렌더된 영상 품질업로드 초안으로 안 감
승인 6업로드업로드 메타 초안업로드 안 됨(외부 액션 보호)
승인은 "이 단계 승인하고 진행" 버튼 하나입니다. 수정이 필요하면 그 단계에서 고친 뒤 통과시키면 됩니다. 승인 전엔 다음 단계로 절대 안 넘어가므로 안심하고 검토하셔도 됩니다.

⚙️ 뒤에서 도는 자동 인프라 (사장님이 신경 안 써도 되는 것)

CDP 크롬 자동 운영

launchd 상시 — 재부팅·크롬 종료 시 자동 기동·부활(1~3초). 발굴 크롤링용 크롬이 항상 살아있습니다. 창은 숨김(minimized)이라 화면에 안 보입니다.

자동 로그인 유지

구글 OAuth — 구글 로그인이 프로필에 유지돼, 재부팅해도 Viewtrap이 자동 재로그인됩니다. 사장님이 한 번 로그인해두면 끝.

AI 의도 분류

Claude Sonnet 고정 — 발굴한 영상이 "우리 타깃이 볼 주제인지, 판매논리가 녹는지"를 판단(적합/모호/부적합).

성과 자동 수집

YouTube API — 디립다 채널 OAuth 연동. 조회·시청·구독은 즉시, 노출·CTR은 Reporting API(하루 뒤 데이터).
