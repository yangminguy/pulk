5 정직한 잔여 단서 (완료지만 알아둘 것)

① 라이브 실행 트리거

runner-adapter는 thin — POST는 run을 queued로 저장하고, harness-pipeline의 실제 agent CLI 실행은 주입형 runner 인터페이스로 추상화돼 있습니다. 실 CLI 연결은 기존 runner 데몬과의 배선 1스텝이 남음(인터페이스 완비, mock으로 전 경로 테스트됨).

② 팀 라이브 = 현재 solo

cto.ts 라이브 경로는 단일 task를 1 feature로 분해 → 현재는 solo run만 방출. 다중 패키지 팀런은 구현·테스트 완료지만 다중 feature 입력이 들어와야 작동(잠재 활성).

③ retry 엔드포인트

Control Room retry 버튼은 POST /api/monitor:retryRun 서버 액션이 있어야 실동작. 현재 graceful degrade(미연결 시 안전 표시). orchestration 플러그인에 액션 추가가 후속.

④ .claude/* gitignore

.claude/rules·settings.json(hook 등록)는 양 repo 모두 gitignore라 로컬에서만 동작·버전관리 제외. hook 스크립트(scripts/hooks/*.mjs)·context-harness 코드는 커밋됨.
