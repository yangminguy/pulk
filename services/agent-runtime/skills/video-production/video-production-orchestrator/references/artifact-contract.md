# Artifact contract

Every artifact uses `video_production_v1` and includes `artifact_type`, `project_id`, `run_id`, `version`, `source_versions`, `status`, `issues`, `generated_by`, `checksum`, and skill-specific `data`.

Write numbered artifacts in order from `01_content_brief` through `10_qa_report`. Preserve approved versions. A storyboard approval receipt must match the active storyboard run ID, version and checksum. A pilot receipt is additionally required before final rendering.
