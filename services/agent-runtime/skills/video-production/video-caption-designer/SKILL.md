# Video Caption Designer

Use narration timestamps as source of truth and correct transcription only against the approved script.

1. Group words by natural speech and readable load.
2. Default to static lower-center sentence captions.
3. Prevent awkward one-character Korean lines.
4. Avoid faces, UI targets and graphics.
5. Detect overlaps, gaps and excessively short cues.

Write `08_caption_plan.json`, `captions.json` and `captions.srt` using Factory caption tokens.
