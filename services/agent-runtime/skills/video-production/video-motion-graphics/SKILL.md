# Video Motion Graphics

Inspect the current Factory schema and component registry.

1. Reuse supported components and Pulk design tokens.
2. Preserve each fragment's `selected_factory_scene_type`, media subject and composition. Motion may clarify the form but may not replace it with a house template.
3. Define entrance, explanation, hold and exit beats.
4. Finish entrances in 0.25–0.6 seconds and explanatory motion in 0.6–1.5 seconds where possible.
5. Keep one focal movement and lower-center caption space clear.
6. Use restrained motion for photographs and talking head; use explanatory motion for architecture, charts, steps and recorded UI.
7. Flag code changes instead of generating per-video React.

Write `06_motion_plan.json`. Motion must explain causality, comparison, filtering, progression, or viewpoint change.
