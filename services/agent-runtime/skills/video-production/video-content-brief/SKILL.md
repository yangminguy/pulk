# Video Content Brief

Require an approved script and read `constraints.production`. Preserve approved meaning.

1. Separate the click promise from the topic.
2. Identify what the opening and ending must deliver.
3. Preserve stable logic blocks and proof requirements.
4. Mark contradictions, unsupported claims and missing inputs as blockers.
5. Record source versions for every input.

Write `01_content_brief.json`. Block when the script is unapproved, the promise conflicts with the script, or required evidence cannot be stated safely.
