# CMO Insight Loop — 분석 방법론

> Hook Pattern Lab(썸끝원끝) 7단계 분석을 자동 루프용으로 압축한 것.
> 모든 분석의 중심 질문은 하나다: **"사람들이 이걸 왜 봤는가?"**

## 0. 분석 순서 (영상 1개당)

```text
① 시청 동기 가설      — 이 영상의 클릭/시청을 만든 단일 핵심 포인트는 무엇인가
② 썸네일 분석          — 그 포인트를 썸네일이 어떻게 유도했는가 (이미지+문구 구조 분해)
③ 제목 분석            — 그 포인트를 제목이 어떻게 유도했는가
④ 도입부 30초 분석     — 클릭 약속이 도입부에서 어떻게 회수/증폭됐는가
⑤ 일관성 체크          — 썸네일→제목→원고가 같은 약속을 관통하는가, 어디서 강화되는가
⑥ 적용 루트            — 내 콘텐츠(마케팅 자동화 상품)에 그대로 대입하는 구체적 방법
```

원고는 전문을 읽지 않는다. 도입부 30초 + 본문 앞부분으로 핵심 논지만 파악한다.

## 1. 시청 동기 가설

- 시청자의 현재 상태(고통/현상)와 욕구(되고 싶은 상태)를 한 문장으로.
- 클릭 약속(promise): "이걸 보면 ___ 된다"를 한 문장으로.
- 데이터 보조: 조회수 대비 구독자 수(작은 채널의 떡상 = 썸네일/제목 자체의 힘이 큼).

## 2. 썸네일 구조 분해

문구와 이미지를 변수로 치환해 공식으로 만든다.

예시: "거짓말처럼 5분만에 고관절과 엉덩이가 시원해집니다" + 고관절 스트레칭 이미지

```text
[짧은 시간(5분)] 안에 [특정 행동(고관절 스트레칭)] 을 하면 [욕구 충족(시원해짐)] 이 이뤄진다
→ 시청자: 지금 [현상(고관절 아픔)]을 겪고 있음 → 욕구 있음 + 행동만 따라하면 됨 → 클릭
```

체크 항목:
- 문구의 구조 공식 (변수 치환형)
- 이미지가 보여주는 것: 결과인가, 행동인가, 사람(감정)인가, 증거(숫자/화면)인가
- 멈추게 한 요소 1개 (스크롤 스토퍼)
- 숫자/시간/금액 등 구체성 장치
- 희소성/도발/대비 장치

## 3. 제목 분석

- 썸네일과 같은 약속인가, 보완 정보(누가/왜 신뢰)를 더하는가
- 검색 키워드 포함 여부 (탐색 유입 vs 브라우징 유입)
- 구조 공식 (예: [타겟 호명] + [금지/경고] + [구체 수치])

## 4. 도입부 30초 분석

- 첫 문장이 클릭 약속을 어떻게 받는가 (즉시 회수 / 증폭 / 긴장 유지)
- 가장 강한 후킹 문장 1개 + 그 문장이 강한 이유
- 신뢰 장치 (수치, 사례, 권위, 시연)
- 궁금증 장치 (떡밥, 금지, 반전 예고)
- 구조 공식 (예: 문제 제기 → 도발 → 신뢰 구축 → 본론 예고)

## 5. 일관성 체크 (썸네일→제목→원고 관통)

- 세 지점이 하나의 약속을 일관되게 미는가
- 어디서 약속이 가장 강하게 증폭되는가
- 약속과 본문 내용의 간극(낚시 위험)은 없는가 — 간극이 있다면 그게 작동한 이유도 분석

## 6. 적용 루트 (가장 중요한 산출물)

내 상품(마케팅 자동화)에 바로 대입 가능한 형태로 쓴다.

```text
구조 공식: [짧은 시간] 안에 [특정 행동] 하면 [욕구 충족]
내 적용:   "하루 10분, 이 자동화 하나면 블로그·인스타 콘텐츠가 알아서 쌓입니다"
썸네일:    자동화 대시보드 화면 + "10분 셋업" 문구
도입부:    "저는 이제 콘텐츠를 직접 안 만듭니다" (약속 즉시 회수)
```

## 산출물 포맷 (insights/<date>.md)

영상별로:
- `watch_driver`: 시청 동기 한 문장
- `thumbnail_insight`: 구조 공식 + 작동 이유
- `title_insight`: 구조 공식 + 작동 이유
- `intro_insight`: 후킹 문장 + 구조 공식 + 작동 이유
- `consistency`: 관통 분석
- `application_route`: 내 콘텐츠 적용 (썸네일 문구·제목·도입부 첫 문장 초안 포함)

## 피드백 반영

분석 전 반드시 `data/guidelines.md`를 읽고 사장님 피드백(누적)을 분석 기준에 반영한다.
리포트 발송 후 받은 피드백은 guidelines.md에 날짜와 함께 추가한다.
