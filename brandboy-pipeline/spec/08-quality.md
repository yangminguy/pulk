# SPEC 08 — 최종 품질 검수

> **코드 태스크 T6.** 자동 판정 가능한 것만 코드로 검사한다.
> 나머지는 "자동 판정 불가"로 명시하고 **통과 처리하지 않는다.**

## 목적

기술적으로 열린다는 이유로 완성으로 판정하지 않는다. 논지·화면·리듬·오디오·권리까지 검수한다.

---

## 1. 치명 오류

하나라도 있으면 출고하지 않는다.

| # | 항목 | 자동 |
|---|---|:---:|
| 1 | 제목·썸네일의 약속을 본문이 회수하지 않음 | ✕ |
| 2 | 핵심 숫자·인용·사건에 출처가 없음 | ○ |
| 3 | 내레이션과 반대되는 화면 | ✕ |
| 4 | 다른 유튜버의 해석을 사실처럼 사용 | ✕ |
| 5 | 권리 상태가 `blocked` 또는 `unknown` | ○ |
| 6 | 반복 루프가 눈에 띔 | ○ |
| 7 | 자막이 틀리거나 화면 밖으로 나감 | ○ |
| 8 | 내레이션이 잘리거나 원본음과 충돌 | ○ |
| 9 | 상품 연결이 앞의 문제와 이어지지 않음 | ✕ |
| 10 | 계획되지 않은 `fallback_text`가 남아 있음 | ○ |
| 11 | 훅 30초의 시각 변화가 12개 미만 | ○ |
| 12 | reveal 구간에 직접 증거가 없음 | ○ |

**✕ 항목을 코드가 "통과"로 처리하면 안 된다.** `"verdict": "human_required"`로 출력한다.

---

## 2. 정량 리포트

`qc-report.json` — 모든 기준값을 `edit-profile.json`과 대조한다.

```json
{
  "duration": 879.2,
  "shot_count": 362,
  "mean_shot_duration": 2.43,
  "intro_visual_changes": 15,
  "a_roll_ratio": 0.16,
  "motion_ratio": 0.08,
  "caption_card_count": 7,
  "stock_ratio": 0.04,
  "critical_beats_covered": 1.0,
  "traceable_external_shots": 1.0,
  "stagnant_ranges": [],
  "same_source_runs": [],
  "rights_open": [],
  "checks": [
    { "id": "intro_visual_changes", "value": 15, "range": [12, 20], "pass": true },
    { "id": "title_promise", "verdict": "human_required" }
  ]
}
```

**수치가 기준 안에 있다는 이유만으로 통과시키지 않는다.** 이상 구간을 찾기 위한 도구다.

## 3. 수정 목록

`fix-list.json`

```json
[{
  "priority": "P0",
  "range": "02:14.2-02:17.8",
  "type": "evidence",
  "problem": "가격을 말하지만 제품 가격이 보이지 않음",
  "action": "공식몰 캡처로 교체"
}]
```

- `P0` 사실·권리·논지 오류
- `P1` 이해와 이탈에 큰 영향 (도입 30초 화면 부족은 여기)
- `P2` 리듬·디자인·마감

**P0가 0이 될 때까지 출고하지 않는다.**

---

## 4. 사람 검수 — 네 번의 시청

코드가 대신할 수 없다. `qc`는 이 체크리스트를 출력만 한다.

### 1차 · 화면 없이 듣기
원고만으로 이해되는가 / 논지 전환이 자연스러운가 / 정보가 너무 오래 이어지는가 / 결론이 앞의 증거에서 나오는가

### 2차 · 소리 없이 보기
화면만 봐도 무엇을 말하는지 짐작되는가 / 같은 크기와 색이 반복되는가 / 정지 구간이 보이는가 / 제품·인물·숫자가 충분히 보이는가

### 3차 · 모바일 크기
자막과 출처가 읽히는가 / 제품·문서의 중요한 부분이 보이는가 / 모션그래픽의 수치가 읽히는가

### 4차 · 전체 실시간
첫 30초 약속 / 중간 이탈 예상 구간 / 진행자 리셋 / 음악 에너지 / 결론과 CTA

**배속 검수만으로 최종 승인하지 않는다.**

> 첫 3편까지는 2차와 4차만 해도 된다. 화면 문제는 소리를 끄면 즉시 드러나고, 지루함은 실시간으로만 느껴진다. 1·3차는 편수가 쌓인 뒤 추가한다.

## 5. 구간별 체크리스트

### 첫 30초
- 제목·썸네일에서 약속한 대상과 결과가 보인다
- 브랜드 이름만 소개하지 않고 긴장이나 질문이 있다
- 가장 강한 제품·가격·결과 화면을 아끼지 않는다
- 채널 소개와 긴 인사를 넣지 않는다
- 12~20개의 의미 있는 시각 변화가 있다

### 정보 구간
- 주장 뒤에 근거 또는 실제 장면이 온다
- 연도와 역사를 나열하지 않는다
- 20~40초마다 질문·사례·반전·관점 중 하나가 있다

### 강조와 사운드
- 강조 카드가 일반 자막을 크게 만든 것이 아니라 반전·숫자·결론을 정지시키는가
- 강조 문구와 발화가 0.2초 안에서 맞는가
- 모든 강조에 같은 효과음을 반복하지 않는가
- 막 경계의 음악 변화가 원고의 감정 변화와 맞는가

### 관점
- 성공담 요약과 구분된다
- 퍼널의 어느 단계가 바뀌었는지 보여준다
- 고객 행동이 왜 변했는지 설명한다
- 그대로 베끼면 실패할 조건을 말한다

### 결론
- 시청자가 시험할 최소 행동이 하나다
- 상품 연결이 새 광고 문구처럼 붙지 않는다
- CTA가 하나다

---

## 6. 완료 조건

- 치명 오류 0개 (자동 8종 + 사람 4종)
- 모든 핵심 주장 화면과 출처 확인
- 최소 2회 시청 완료 (소리 없이 · 실시간)
- P0 수정 0개
- 출처 및 화면 자료표 생성
- 제목·썸네일·원고·CTA가 하나의 목적을 향함
- hook·build·reveal·punch의 기능과 사운드 전환 확인
