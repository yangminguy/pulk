# SOUND BIBLE — 내레이션·원본음·음악

## 1. 내레이션

- 한 편을 연속 녹음
- NG 후 3초 쉬고 문장을 다시 읽음
- Whisper 정렬로 마지막 성공 테이크 선택
- 호흡과 룸톤을 자연스럽게 유지
- 문단마다 핵심 한두 단어만 강세
- 반전 직전 0.2~0.5초 멈춤 가능
- 씬별 정규화 금지, 전체 마스터를 한 번 처리

---

## 2. 원본음

원본음의 세 역할:

- `quote`: 창업자·전문가의 핵심 발언
- `moment`: 관객·공장·행사·광고의 현장감
- `bridge`: 다음 장면을 먼저 들려주는 J-cut

권장:

- 45~120초마다 의미 있는 원본음 순간 검토
- 길이 2~9초
- 내레이션과 동시 발화 금지
- 외국어는 원문·번역 자막 구분
- 발언 맥락을 바꾸는 절단 금지

---

## 3. 음악

막마다 역할을 기록한다.

| 막 | 역할 |
|---|---|
| hook | 긴장·질문 |
| build | 탐색·진행 |
| reveal | 상승·반전·짧은 무음 |
| punch | 정리·여운 |

한 곡을 처음부터 끝까지 깔지 않는다. 막 경계·핵심 반전·결론에서 에너지를 조정한다.

---

## 4. 효과음

사용 가능:

- 숫자 카드
- 챕터 전환
- 반전 카드
- 문서 하이라이트
- 제품 디테일 진입

금지:

- 모든 자막 팝
- 모든 컷
- 같은 효과음의 반복
- 목소리보다 큰 임팩트

15분 기준 10~25개의 의미 있는 SFX로 시작하고 필요 없으면 제거한다.

---

## 5. 믹스

- 내레이션이 항상 최우선
- BGM 덕킹은 문장 전체가 아니라 필요한 구간에 자연스럽게
- 원본음 진입 전 BGM을 낮추거나 비움
- 최종 프로그램 약 -14 LUFS integrated를 시작점으로 확인
- true peak -1 dBTP 이하
- 이어폰·노트북·휴대폰 스피커에서 모두 검수

수치보다 말의 명료도와 장면 전환의 감정이 우선이다.
