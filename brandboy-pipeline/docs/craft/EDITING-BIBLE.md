# EDITING BIBLE — 브랜드보이형 화면 문법

## 1. 컷은 시간이 아니라 의미로 자른다

다음 중 하나가 바뀌면 새 화면 후보가 필요하다.

- 인물
- 제품
- 행동
- 장소
- 시대
- 숫자
- 원인과 결과
- 사실과 해석
- 질문과 답

예:

> “새티스파이의 티셔츠 한 장은 45만 원이지만, 사람들은 계속 사고 있습니다.”

최소 네 샷이다.

1. 새티스파이 제품
2. 공식몰 가격
3. 품절 또는 구매 화면
4. 실제 러너와 브랜드 문화

---

## 2. 막별 컷 프로필

### Hook

- 샷 길이: 0.8~2.2초 중심
- 30초 안에 12~20개의 시각 변화
- 결과·가격·유명인·제품·반전 화면을 먼저 보여줌
- 역사 설명 금지
- 진행자 인사보다 증거 화면 우선
- 가장 강한 임팩트 카드 1개 사용 가능

### Build

- 샷 길이: 2~4초 중심
- 인물→행동→제품→디테일→문서 순환
- 창업자 인터뷰는 얼굴만 오래 두지 않고 관련 B-roll과 L-cut
- 연도 나열보다 사건과 선택을 보여줌
- 45~75초마다 진행자 리셋

### Reveal

- 샷 길이: 1.3~3초 중심
- 주장→증거→반대 사례→진행자 해석
- 같은 원본을 다양한 구간에서 재배치
- 숫자·가격·발언 원문을 화면으로 증명
- 임팩트 카드와 짧은 무음을 가장 효과적으로 사용할 구간

### Punch

- 샷 길이: 2.5~5초 중심
- 진행자 화면 비중을 높임
- 앞에서 사용한 가장 상징적인 화면을 한 번 회수
- 음악 에너지를 정리
- CTA는 한 행동만 남김

---

## 3. 반복 사용하는 샷 시퀀스

### 주장–증거–해석

1. 진행자 또는 내레이션으로 주장
2. 제품·문서·발언으로 증명
3. 결과 장면
4. 진행자 해석

### 인물 소개

1. 이름과 얼굴
2. 실제 행동
3. 과거 사진
4. 인터뷰 원본음
5. 인물이 만든 제품이나 결과

### 숫자 공개

1. 숫자가 의미하는 문제
2. 전체 화면 숫자 카드
3. 공식 자료 또는 그래프
4. 현실 장면

### 반전

1. 사람들이 믿는 일반론
2. 0.1~0.4초 호흡 또는 짧은 무음
3. 임팩트 카드
4. 반대 증거 2~3개 빠르게 교차
5. 진행자 해석

### 제품 설명

1. 전체 제품
2. 사용 장면
3. 소재·봉제·기술 디테일
4. 가격
5. 소비자 반응

---

## 4. 화면 크기 리듬

다섯 단계가 반복되도록 한다.

```text
wide → person → product → detail → proof
```

같은 크기의 인터뷰 얼굴, 제품 정면, 기사 캡처가 세 번 연속 나오면 교체한다.

---

## 5. A-roll

권장 비중은 전체의 10~20%다.

사용 위치:

- 훅의 질문
- 새 막 시작
- 반론
- 디립다의 해석
- 시청자에게 적용 질문
- 결론과 CTA

A-roll을 외부 영상이 부족한 곳의 메움 화면으로 쓰지 않는다.

배경에 브랜드 화면을 합성할 때 진행자의 얼굴·손·자막이 겹치지 않도록 프레이밍한다.

---

## 6. 전환

기본은 하드컷이다.

- 디졸브: 시간 경과·역사 사진
- 매치컷: 형태·행동이 이어질 때
- 푸시·줌: 문서나 제품 디테일 진입
- 플래시·글리치: 기본 금지
- 장식성 트랜지션: 막 경계에서도 남용 금지

---

## 7. 정지 이미지

- 2~4초 사용
- 3초 이상이면 강조할 위치가 있어야 함
- 얼굴 사진은 눈을 향해 아주 느리게 이동
- 문서는 핵심 문장으로 확대
- 제품은 디테일을 순서대로 보여줌
- 자동 켄번즈를 모든 이미지에 적용하지 않음

---

## 8. 자동 경고

- 훅 30초 시각 변화 12개 미만
- 7초 이상 같은 시각 정보
- 같은 소스 3샷 연속
- 같은 화면 크기 4샷 연속
- 인터뷰 얼굴 8초 이상
- 75초 이상 진행자 리셋 없음
- 숫자를 말하지만 숫자 화면 없음
- 제품을 말하지만 제품이 보이지 않음
- reveal에 근거 화면 없이 진행자 주장만 존재
