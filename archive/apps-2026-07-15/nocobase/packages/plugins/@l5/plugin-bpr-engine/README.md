# @l5/plugin-bpr-engine

BPR 로깅 및 개선 추적 (P1 Essential).

## 책임

- 실행 결과 로깅 (Business Process Review)
- 워크플로우 개선 제안 생성/추적
- 학습 루프: 결과를 학습해 다음 실행 개선

## L5 Core 연동

- BPR 분석 및 워크플로우 개선 제안 함수 (l5-core에서 제공 예정)
