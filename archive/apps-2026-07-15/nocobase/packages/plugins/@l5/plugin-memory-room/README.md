# @l5/plugin-memory-room

인사이트 저장 및 검색 (P1 Essential).

## 책임

- 누적 인사이트 저장/검색 (Memory Room)
- 인사이트를 사업 기획/실행에 재공급
- 고객 PII와 재사용 가능한 인사이트 분리 (`pii_level` 필수)

## L5 Core 연동

- 인사이트 분류 및 검색 함수 (l5-core에서 제공 예정)

## Collections

- `memory_entry`
