CMO Video Room 실제 구현 점검

PRD v1.1 기준 · 코드 읽기가 아니라 실제 서버 호출·테스트 실행으로 검증 · 2026-06-05

작동 실제로 동작 확인 껍데기/부분 코드 조각만 있고 연결 안 됨 없음 구현 자체가 없음

한 줄 결론

지금 화면에 보이는 Video Room은 “겉모습 일부 조각”만 있고, PRD가 말한 제품으로는 거의 작동하지 않습니다.

부품(카드 디자인·스키마·평가 로직)은 여기저기 만들어졌지만, 서로 연결되어 있지 않고, 가장 중요한 CMO와의 대화 기능은 백엔드가 통째로 빠져 있어 작동하지 않습니다. PRD 성공 기준 20개 중 완전히 충족된 항목은 0개입니다.

작동 0~1
없음 70%

초록(작동) ≈ 4% · 노랑(껍데기/부분) ≈ 26% · 빨강(없음) ≈ 70% — PRD 성공기준 20개 + 데이터모델 15개를 종합한 체감 비율

① 지금 “CMO랑 대화가 안 돼” — 왜 그런가

실제로 서버에 직접 요청을 보내 확인했습니다. 결과는 명확합니다.

테스트한 것: 화면이 CMO에게 메시지 보낼 때 부르는 주소 POST /api/cmo:chatMessage

서버 응답: HTTP 404 Not Found — “그런 기능은 서버에 없습니다”

비교용: CEO 채팅(/api/chat:submitInstruction)과 CTO(/api/cto:planMessage)는 정상(401=로그인 필요)으로 응답합니다. 즉 다른 대화는 살아있고 CMO만 죽어 있습니다.

근본 원인 (둘 다 사실)

1
CMO 대화의 백엔드(서버 쪽 두뇌)가 아예 안 쓰여졌습니다.
화면(프론트엔드)에는 “CMO에게 마케팅 전략을 이야기하세요…” 입력창과 전송 코드가 있습니다. 그런데 그 요청을 받아 처리할 서버 기능(cmo 리소스)이 지금 코드(메인 브랜치)에도, 이번에 통합한 브랜치에도 둘 다 존재하지 않습니다. 화면만 만들고 서버는 안 만든 상태입니다.
2
지금 켜져 있는 서버는 이번 작업물도 아닙니다.
현재 돌아가는 백엔드(:13000)는 이번 CMO 작업이 들어있지 않은 예전 메인 브랜치입니다. 설령 화면을 새 빌드로 띄워도, 받아줄 서버가 옛날 것이라 어차피 연결되지 않습니다.
쉽게 말하면 — 전화기(화면)는 만들었는데, 전화를 받을 교환국(서버)을 안 만들었습니다. 그래서 “여보세요”를 해도 신호가 끊깁니다. 교환국을 새로 만들어 연결해야 대화가 됩니다.

⑥ 비개발자용 한 장 요약

  • 대화가 안 되는 건 버그가 아니라 “안 만들어진 것”입니다. CMO 대화의 서버 쪽이 통째로 빠져 있어요. 고치려면 새로 만들어야 합니다(수리가 아니라 신축).
  • 지금 브라우저에 뜬 Video Room은 빈 디자인 뼈대입니다. 탭·로드맵·카드·승인 패널 등 PRD 핵심이 들어있지 않습니다.
  • “158개 작업 완료”의 결과물은 흩어진 부품들입니다. 카드 디자인 몇 개, 스키마 몇 개, 평가 로직, 가짜 연결 어댑터 — 하지만 하나의 작동하는 제품으로 조립되지 않았습니다.
  • PRD의 심장인 “리서치 → 승인 게이트 → 콘텐츠 세트” 흐름은 데이터 구조부터 없습니다. 15개 핵심 데이터 중 13개가 코드에 존재하지 않습니다.
  • 좋은 소식: 로그인·사업선택·CEO 대화 같은 기반은 멀쩡합니다. 디자인 토큰과 레이아웃 뼈대도 있어, 다시 제대로 조립하면 속도는 붙습니다.
